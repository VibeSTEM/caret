# JetBrains Mono

Caret embeds the static Regular, Bold, Italic, and Bold Italic faces from the official [JetBrains Mono v2.304 release](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304). The font files and the upstream SIL Open Font License 1.1 are kept together in this directory. The package builder copies the license into the installed application's `licenses` directory. The license wording is unchanged; trailing whitespace is normalized.
