# Caret

Caret 是轻量的所见即所得结构化编辑器，计划用 Rust 实现领域规则，用 Qt 6 / QML 实现桌面界面。产品目标和里程碑见[需求与范围](ai-docs/architecture/requirements.md)。

仓库目前处于规划阶段，尚未建立 Cargo、CMake、QML 和 CI 工程。文档中的构建命令、crate 和目录是目标约定，不能作为当前可运行的入口。
