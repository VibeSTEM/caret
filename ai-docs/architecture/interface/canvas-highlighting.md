# 画布与交互背景

更新日期：2026-10-30。本文统一定义正文环境高亮和命令提示背景的渲染层、数据来源及复用边界。此前这些规则分散在命令输入、结构导航和 031 任务中，没有专门的架构文档；本文现作为三类背景渲染分层的权威说明。命令行为见[命令输入](../editor/command-input.md)，环境语义和高亮交互见[结构导航](../editor/structure-navigation.md)与[031 当前环境背景高亮](../../task/031-environment-highlight.md)。

## 两个渲染层

Caret 有两类不同用途的背景：

| 背景 | 表示什么 | 渲染位置 | 几何来源 |
| --- | --- | --- | --- |
| 块环境高亮 | 当前光标所在的块环境范围 | 文档画布 QSG 场景图；纸张之上、选区与字形之下 | Rust 根据当前结构和同代布局快照生成的分页矩形 |
| 行内环境高亮 | 当前光标所在的行内环境文本范围 | 与块环境共用 QSG 环境高亮层；选区与字形之下 | Rust 从环境文本范围及同代 Parley 布局生成的视觉行矩形 |
| 命令提示背景 | 正在输入的命令查询/候选控件 | QML 命令输入/补全控件自身的背景 | QML 控件的内容尺寸、候选尺寸和插入点锚定位置 |

块环境和行内环境是文档画布内容的临时视觉投影。它们必须与页面缩放、分页裁剪、文字、选区和光标处于同一画布坐标与场景图顺序中。块环境和行内环境均由 QSG 绘制。Rust 提供语义范围及布局几何，Qt 校验和投影快照，QSG 在字形之前绘制背景；这些层不遍历文档树、不重复塑形，也不改写文档或布局状态。

命令提示是一个可交互的界面控件，不是文稿内容。它跟随插入点弹出，尺寸由查询和候选内容决定，并需要自己的内边距、焦点和指针命中区域。因此背景属于 QML 控件自身，随控件一起布局和交互；它不进入正文画布的 QSG 文稿层，也不遮盖正文的环境高亮状态。

## 复用边界

块环境和行内环境共享同一个 QSG 环境高亮绘制实现：绘制器消费矩形列表与样式参数，不理解环境 kind，也不计算文档范围。两者可以有独立的颜色 token 与各自的几何策略；共享绘制、裁剪、圆角和节点更新机制，不能复制两套平行的 QSG renderer。

命令提示与环境高亮可以共享设计令牌或视觉约定，例如主题色管理方式、圆角规范；但 QML `HighlightBackground` 和 QSG 节点属于不同渲染及交互边界，不能为了“共用背景”把命令弹出控件移入文稿场景图，也不能让 QML 重建正文环境几何。只有确实跨两种渲染系统共用且保持纯数据的样式定义，才应抽为共同主题属性；绘制代码应留在各自的渲染层。

三类背景使用独立的语义颜色 token。环境高亮颜色、圆角和留白由 GUI Theme 提供；命令提示按自身控件尺寸处理内边距，环境高亮按 Rust 布局矩形绘制，不把命令控件的留白直接套到正文范围上。所有背景均为界面状态，不序列化到 `.cdoc`。

## 场景图顺序

文稿画布的相关顺序为：

```text
页面背景
  → 块/行内环境高亮（同一层；由当前状态选择应显示的几何）
  → 文本选区
  → 字形
  → 光标
```

命令提示控件位于该文稿内容层之外，按 QML 弹出控件的锚定与焦点规则显示；命令模式可以与环境高亮同时存在。当前快照解析失败或当前代际的几何无效时，清除环境高亮，避免旧矩形残留；若收到与当前 document/font generation 不一致的迟到交互结果，则直接丢弃，不能让旧结果覆盖或清除较新的有效高亮。被识别为可恢复的旧局部布局快照时，保留当前已安装状态并请求完整快照。

具体结构高亮交互由[结构导航](../editor/structure-navigation.md)定义；031 记录行内环境高亮的接入与验收状态，并复用环境 QSG 绘制层。
