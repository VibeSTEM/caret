# 界面外壳

更新日期：2026-10-25。原子组件和通用对话框从参考实现移植，装配方式按这篇来。

## 窗口

```text
┌──────────────────────────────────────────────────────────┐
│ 自定义标题栏：系统窗口按钮、文档名、搜索、设置齿轮        │
├──────────────────────────────────────────────────────────┤
│ Home                          Comments   Editing   Share │
├──────────────────────────────────────────────────────────┤
│                     页面占位，居中                        │
├──────────────────────────────────────────────────────────┤
│ 页码、字数、语言                              缩放尺      │
└──────────────────────────────────────────────────────────┘
```

标题栏画进系统标题区域，保留平台窗口按钮和缩放边框。工具栏只留 Home，右侧是 Comments、Editing 和 Share。不放 Discord，也不放账户头像；最右侧是设置齿轮，打开已有的设置对话框。

底栏左侧是页码、字数和语言，右侧只留缩放尺。页面在编辑区里居中，008 之前是占位，不接收输入。标题、列表、公式和表格从 `\` 或快捷键来。设置和语言用移植来的对话框，字段跟 Caret 的设置 schema，不保留参考仓库里的工艺项。

无边框使用扩展客户区，标题栏避让系统窗口按钮。拖动和双击交给平台窗口管理器。

窗口最小尺寸按内容定：要能放下一页的版心宽度和状态栏。不照抄别的应用的工作区下限。

## 谁画什么

- **C++ 画布**持有最新的页面快照。它绘制页面、插入点和选区，做命中，接收 IME，并把键变成命令。焦点框用结构栈和布局范围来画，不另排一次。
- **QML** 画标题栏、状态栏和对话框。补全列表是锚定在插入点附近的一层，数据来自 ViewModel 上的候选数组。它不抢画布的键盘焦点：按键先到画布，命令模式认领之后，列表只反映 `selected`。
- 颜色、间距和字号来自 `Theme.qml`。见 [DSL](../../standards/dsl.md)。

## 线程

ViewModel 活在 GUI 线程。打开和保存的读写可以在 worker 里做，结果回到 GUI 线程再换 `Session`。窗口已经关掉时，不再碰 ViewModel。

缩放用设备像素比在 C++ 里换算。QML 只用逻辑像素。不把屏幕编号写进文档或设置。
