# 界面外壳

更新日期：2026-10-28。原子组件和通用对话框从参考实现移植，装配方式按这篇来。

## 窗口

```text
┌─────────────────────────────────────────────────────────────────────┐
│ AutoSave、打开/保存、撤销/重做 │ 文件名 │ Comments、模式、Share、搜索、设置 │
│ Home                                                                │
├─────────────────────────────────────────────────────────────────────┤
│                     页面占位，居中                                    │
├─────────────────────────────────────────────────────────────────────┤
│ 页码、字数、语言                                            缩放尺      │
└─────────────────────────────────────────────────────────────────────┘
```

标题栏画进系统标题区域，保留平台窗口按钮和缩放边框。macOS 系统按钮位于左侧，Windows/Linux 系统按钮位于右侧，内容按平台避让。第一行左侧依次是 AutoSave、打开、保存、撤销、重做；文件名居中；右侧依次是 Comments、工作模式、Share、单图标搜索和设置。不放 Home 图标或更多菜单。图标资源样式另行由产品统一调整。

AutoSave 开关对应 Rust 持久化的全局用户偏好，默认关闭；文档运行状态按会话独立。开启时已有可写 `.cdoc` 路径的文档立即受 AutoSave 管理；当前文档未命名时立即打开另存为，只有选择路径并写入成功后才保持开启。用户取消另存为时开关恢复关闭。应用在已保存的开启偏好下以未命名文档启动时同样请求另存为；直接打开已有 `.cdoc` 不弹路径选择。保存错误和外部文件冲突通过开关的状态提示呈现，文档标题仍由统一的 `Edited`、`Saving`、`Saved` 生命周期状态控制。Rust 决定状态和保存时机；Qt 只在 Rust 提供的单次 deadline 到期时唤醒策略，QML 不运行定时器或自行保存。

多窗口同时开启时，Rust 按活动窗口优先顺序串行请求未命名文档的保存路径；全部成功后提交全局开启偏好，任一取消或失败会回滚本次开关操作，先前成功另存的文档保留路径。

启动时若有恢复条目，先展示恢复选择；恢复在 worker 中验证 `.cdoc` 并准备临时 dirty 会话，安装完成后再执行开启 AutoSave 所需的路径选择。恢复项在取消或恢复失败时保留，只有另存成功或明确丢弃后删除。恢复区读改写由跨进程锁串行化，活动会话持有的恢复项从列表隐藏并拒绝其他实例加载或删除；恢复时先锁住来源，成功安装新会话后才移除来源。新建的冲突快照在写入时立即持有会话租约，避免被其他实例在绑定前取走。自动保存检测到文件外部变化、不可用或摘要不符时拒绝覆盖并保存本地快照；手动保存允许另存副本、备份外部原始字节后替换，或取消。AutoSave 开启期间关闭 dirty 文档时先 flush；失败或仍有新 revision 时复用 Save / Don't Save / Cancel 关闭提示。

第二行只保留 Home 页签，与第一行之间不画分隔线。模式菜单展示 Edit、Review、View 及简短说明。当前 QML 只维护选择器的临时显示状态；编辑权限、修订记录和只读约束由后续任务实现，不据此声称对应行为已生效。

底栏左侧是页码、字数和语言，右侧只留缩放尺。页面在编辑区里居中，008 之前是占位，不接收输入。标题、列表、公式和表格从 `\` 或快捷键来。设置和语言用移植来的对话框，字段跟 Caret 的设置 schema，不保留参考仓库里的工艺项。

无边框使用扩展客户区，标题栏避让系统窗口按钮。拖动和双击交给平台窗口管理器。

窗口最小尺寸按内容定：要能放下一页的版心宽度和状态栏。不照抄别的应用的工作区下限。

## 弹窗与弹性尺寸

- 对话框优先按内容的 `implicitWidth` / `implicitHeight` 和主题间距计算尺寸；尺寸绑定应随翻译、字体度量和可选说明变化。不要用字号、控件高度和若干间距相加来猜测文本会占几行。
- 公共标题栏以标题实际行高和垂直内边距计算高度，并以 `Theme.titlebarHeight` 作为最小高度。公共 `DialogFrame` 暴露标题栏实际高度，内容弹窗据此加内容隐式高度、间距和边距。
- 只有需要稳定工作区或可滚动视口时才固定对话框尺寸，例如设置窗口、新建文档表单和恢复列表。固定尺寸应由 Theme token 管理；可变文本必须换行，长列表/长内容必须在内部滚动，避免扩大到屏幕之外。
- 为中英文等长度不同的界面文案检查实际几何：短文本不留下多余的垂直空区，长文本不裁剪、不压住按钮。可选错误说明出现或消失时，弹窗尺寸应跟随内容变化。

## 谁画什么

- **C++ 画布**持有最新的页面快照。它绘制页面、插入点和选区，做命中，接收 IME，并把键变成命令。hover 和拖选预览留在画布；鼠标释放时提交最终插入点或选区到 Rust。焦点框用结构栈和布局范围来画，不另排一次。
- **QML** 画标题栏、状态栏和对话框。补全列表是锚定在插入点附近的一层，数据来自 ViewModel 上的候选数组。它不抢画布的键盘焦点：按键先到画布，命令模式认领之后，列表只反映 `selected`。
- 颜色、间距和字号来自 `Theme.qml`。见 [DSL](../../standards/dsl.md)。

## 线程

ViewModel 活在 GUI 线程。打开和保存的读写可以在 worker 里做：打开成功后回到 GUI 线程安装新 `Session`；保存只回报其捕获 revision 的写入结果，不替换正在编辑的 `Session`。窗口已经关掉时，不再碰 ViewModel。

缩放用设备像素比在 C++ 里换算。QML 只用逻辑像素。不把屏幕编号写进文档或设置。
