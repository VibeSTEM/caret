# 需求与范围

更新日期：2026-10-25。

## 目标

做一个轻量编辑器：所写即所排。结构随时能用键盘进出。命令用 `\` 输入，不靠一排不会用的按钮。

## 功能

| 编号 | 需求 | 要点 | 里程碑 |
| --- | --- | --- | --- |
| R1 | 能写完一篇 | 打开、编辑、保存 `.cdoc`；窗口里看到分页结果 | M0 |
| R2 | `\` 命令 | `\` 进入命令模式，补全，Enter 或 Tab 执行，Esc 取消并清掉已输入的内容，空格无效；整条命令一个撤销步 | M1 |
| R3 | 别名 | `\section`、`\frac` 这类名字映射到命令 id 和参数 | M1 |
| R4 | 输入法 | 组字期间不进入命令模式 | M1 |
| R5 | 结构导航 | 在段落、标题、列表项、公式、表格之间跳转；能进入和离开；当前结构有可见边界 | M2 |
| R6 | 公式 | 用 `\` 或 `$` 插入；公式内部可移动；可以吃进 LaTeX 片段 | M3 |
| R7 | 表格 | 插入、在单元格间移动、增删行列；单元格里可以是普通段落 | M3 |
| R8 | 编辑仍然轻 | 普通按键只重排受影响的段落。毫秒数在有基准之前不写进门禁 | M4 |
| R9 | 环境操作 | 块级环境创建、嵌套、删除和提升通过命令/结构快捷键提供，不新增专用环境工具按钮 | M2 |
| R10 | 跨平台与多语言 | Windows/macOS/Linux 的文本编辑遵循统一 Unicode 边界；按文档语言信息进行脚本 shaping、双向布局和语言相关断行；字体按系统回退。字体度量可因平台而异 | M0–M4 |

## 非目标

- 对齐文字处理软件的功能面：邮件合并、修订、批注、引文管理、艺术字。
- TeXmacs 的 Scheme 扩展和 `.tm` 文件。
- 协同编辑和云同步。
- 把 docx 当作原生格式。原生格式只有 `.cdoc`。
- 插件和脚本宏。

Markdown、LaTeX、PDF 的导入导出可以以后单独立项，不进入上面的里程碑。

## 里程碑

| 里程碑 | 用户能做什么 |
| --- | --- |
| M0 | 打开空文档，打字，保存，再打开 |
| M1 | 用 `\` 改标题、列表和换页 |
| M2 | 用键盘在结构之间移动，并看见当前结构 |
| M3 | 写公式和表格 |
| M4 | 用一份长文档看排版是否仍只碰脏段落 |

M0 的窗口是 [007](../task/007-ui-m0.md)，打开、打字和保存是 [008](../task/008-impl-document.md)。其后的里程碑在同一扇窗口上加能力。队列见[任务索引](../task-index.md)。
