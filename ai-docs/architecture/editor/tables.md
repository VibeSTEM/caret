## 模型与导航

Table 是 Block。每个单元格持有普通 Caret 块序列，因此可包含多个 Paragraph 和公式；第一版不支持单元格合并。单元格不持有 `caret-math` 私有 AST，数学节点仍是通用 Caret 文档节点。实现时复用 Block 共享交互底座；单元格位置、行列增删与格内流由表格适配器提供，不另建一套编辑器级焦点、选择和撤销权威状态。

- 插入默认 2×2；行、列增删是独立的结构命令。
- Tab 到下一格，最后一格再按 Tab 增加一行；Shift+Tab 到上一格。停靠在格内子块的外侧时，仍按所属单元格换格。整表外侧使用相应外部容器的 Tab 语义，当前数学编辑态保留按键优先级。
- Enter 在单元格内创建新段落，不在表格外插入行。
- 普通方向键在折行与文本内容中沿用文本导航。上下键在格内环境边缘先停靠到该环境外侧，再按共享块序列继续移动。到达单元格内容边界时，左右按行优先换格，上下按同列换行。上一块和下一块在表内按行移动。越过表格边界时停靠到整表外前或外后。
- 表格焦点使用共享 block 高亮层：只要焦点在表格内，整张表格（所有 cell）显示完整奶油黄背景，边框始终为实线；当前编辑 cell 的辅助线使用网格外框虚线，切格整体替换，离开表格清空。
- 表格通过共享块外前、内部、外后三态进出。外前光标在左侧首行居中，外后光标在右侧末行居中，分页时使用对应的可见行。朝内部移动进入方向对应的首/末格。Escape 停靠到整表外后，文档两端也可停靠。向外移动时从表格外框查找相邻视觉行。
- Shift+方向键从表格外侧可选中整表。紧邻段落耗尽同方向视觉行后，Shift+↑／↓ 一次纳入整表并保留原选区锚点。物理 Control+Space 在格内逐级扩大到整表，再按时扩到可容纳该范围的父块。没有可扩大范围时保留当前选区。
- 正文、行内公式文本和公式树端点都能参与跨格拖选。整表选区可删除、替换和撤销。格内选择沿用各自的文字或数学范围。
- 表格边框从 `TableGridLayout` 规则线输出为页面线条；native 在设备像素网格上对齐轴线与宽度，保证 Enter 改变行高后边框粗细一致。
- 单元格行列、段落与公式位置及上限见[文档位置](document-model/document-position.md)。

表格模型、单元格编辑和保存往返由[045](../../task/045-table-model-and-editing.md)完成；单元格坐标、裁剪、绘制、命中、光标、公式布局与编辑态辅助线由[046](../../task/046-table-layout-and-canvas.md)接入。列宽等分并受最小内容宽度约束。每列内容区两侧均预留单元格内边距。行高由格内块级测量决定。单元格内 Equation、Align、InlineMath 和块环境复用正文的编辑与画布投影。

## 布局与性能

桌面排版当前支持格内段落、块环境和显示公式。模型允许的嵌套表格、格内分页符和不透明块尚未接入表格排版。[表格排版任务](../../task/046-table-layout-and-canvas.md)

engine 组合表格几何与公式几何；表格模块不依赖 `caret-math`。046 可复用 `caret-grid-layout` 对已测量单元格进行行列定位，但可用宽度下的列宽求解、单元格内容重排、分页、裁剪和命中仍属于文档布局。公式绘制使用 [044 的数学布局](../../task/044-math-layout-and-rendering.md)，并在单元格坐标系和裁剪边界内复用其几何。公式行内与块级投影携带同页单元格归属及内容裁切区。超宽内容的字形、装饰、数学图形、命中与选区使用同一内容区。光标在内容区边缘显示，公式仍按文档中的原始位置编辑。当前 `caret-grid-layout` 的生产消费者包括数学适配器与 `caret-layout::table` 表格网格；表格列宽策略、行高与分页放在 `caret-layout`，engine 只做文档内容测量、快照装配与页面投影。

大表格的目标是只重排 `layoutRev` 变化的单元格内容。整表重排成本在 M4 使用固定代表性宽表记录基线、构建配置、缓存条件和测量方式；测量前不设延迟门槛，也不宣称已有性能收益。
