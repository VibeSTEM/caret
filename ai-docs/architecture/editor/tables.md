# 表格

更新日期：2026-11-09。本文是表格目标模型、单元格内容、导航和增量布局的唯一权威；当前文档 DTO 尚未实现 Table 节点。总体验收见[012](../../task/012-impl-table.md)，实现拆分和公式交叉边界见[公式与表格专题索引](math-and-table.md)。表格作为 Block 接入共享位置、选区、删除和历史协议的要求见[块宿主交互](document-model/block-interaction.md)。

## 模型与导航

Table 是 Block。每个单元格持有普通 Caret 块序列，因此可包含多个 Paragraph 和公式；第一版不支持单元格合并。单元格不持有 `caret-math` 私有 AST，数学节点仍是通用 Caret 文档节点。实现时复用 Block 共享交互底座；单元格位置、行列增删与格内流由表格适配器提供，不另建一套编辑器级焦点、选择和撤销权威状态。

- 插入默认 2×2；行、列增删是独立的结构命令。
- Tab 到下一格，最后一格再按 Tab 增加一行；Shift+Tab 到上一格。该行为由 Rust 表格上下文先处理，再回退正文 Tab 语义。
- Enter 在单元格内创建新段落，不在表格外插入行。
- 方向结构键在单元格间移动，到边缘后才离开表格。
- 单元格行列、段落与公式位置及上限见[文档位置](document-model/document-position.md)。

表格模型、单元格编辑和保存往返由[045](../../task/045-table-model-and-editing.md)接入；单元格坐标、裁剪、绘制、命中、光标和高亮由[046](../../task/046-table-layout-and-canvas.md)接入。

## 布局与性能

engine 组合表格几何与公式几何；表格模块不依赖 `caret-math`。046 可复用 `caret-grid-layout` 对已测量单元格进行行列定位，但可用宽度下的列宽求解、单元格内容重排、分页、裁剪和命中仍属于文档布局。公式绘制使用 [044 的数学布局](../../task/044-math-layout-and-rendering.md)，并在单元格坐标系和裁剪边界内复用其几何。当前 `caret-grid-layout` 的生产消费者只有数学适配器，表格接入尚未实现。

大表格的目标是只重排 `layoutRev` 变化的单元格内容。整表重排成本在 M4 使用固定代表性宽表记录基线、构建配置、缓存条件和测量方式；测量前不设延迟门槛，也不宣称已有性能收益。
