## 模型与导航

Table 是 Block。每个单元格持有普通 Caret 块序列，因此可包含多个 Paragraph 和公式；第一版不支持单元格合并。单元格不持有 `caret-math` 私有 AST，数学节点仍是通用 Caret 文档节点。实现时复用 Block 共享交互底座；单元格位置、行列增删与格内流由表格适配器提供，不另建一套编辑器级焦点、选择和撤销权威状态。

- 插入默认 2×2；行、列增删是独立的结构命令。
- Tab 到下一格，最后一格再按 Tab 增加一行；Shift+Tab 到上一格。该行为由 Rust 表格上下文先处理，再回退正文 Tab 语义。
- Enter 在单元格内创建新段落，不在表格外插入行。
- 方向结构键在单元格间移动；到边缘且存在相邻正文段落时离开表格，表格位于文档末尾时暂保持（v1 限制）。普通方向键在单元格内容首/末边界换格：左右按行优先、上下同列；表格边缘存在相邻正文段落时离开表格，否则保持。文本中间仍按文本导航。
- 表格焦点使用共享 block 高亮层：只要焦点在表格内，整张表格（所有 cell）显示完整奶油黄背景，边框始终为实线；当前编辑 cell 的辅助线使用网格外框虚线，切格整体替换，离开表格清空。
- 表格按块宿主参与进出：相邻正文段落与首/末格之间可用方向键进入/离开（纵向进首/末行，水平进首/末格）；Escape 从 cell 回到相邻正文段落；与其它 Block 保持同一焦点/高亮逻辑。
- 表格边框从 `TableGridLayout` 规则线输出为页面线条；native 在设备像素网格上对齐轴线与宽度，保证 Enter 改变行高后边框粗细一致。
- 单元格行列、段落与公式位置及上限见[文档位置](document-model/document-position.md)。

表格模型、单元格编辑和保存往返由[045](../../task/045-table-model-and-editing.md)完成；单元格坐标、裁剪、绘制、命中、光标、公式布局与编辑态辅助线由[046](../../task/046-table-layout-and-canvas.md)接入。列宽 v1 等分并受最小列宽约束，行高由单元格块级测量决定；单元格内 Equation/Align/InlineMath 与块环境标题/正文复用正文布局与编辑协议。

## 布局与性能

engine 组合表格几何与公式几何；表格模块不依赖 `caret-math`。046 可复用 `caret-grid-layout` 对已测量单元格进行行列定位，但可用宽度下的列宽求解、单元格内容重排、分页、裁剪和命中仍属于文档布局。公式绘制使用 [044 的数学布局](../../task/044-math-layout-and-rendering.md)，并在单元格坐标系和裁剪边界内复用其几何。当前 `caret-grid-layout` 的生产消费者包括数学适配器与 `caret-layout::table` 表格网格；表格列宽策略、行高与分页放在 `caret-layout`，engine 只做文档内容测量、快照装配与页面投影。

大表格的目标是只重排 `layoutRev` 变化的单元格内容。整表重排成本在 M4 使用固定代表性宽表记录基线、构建配置、缓存条件和测量方式；测量前不设延迟门槛，也不宣称已有性能收益。
