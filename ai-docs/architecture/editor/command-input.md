# `\` 命令输入

更新日期：2026-10-29。键位总表见[快捷键](../interface/keyboard-shortcuts.md)。

## 状态

命令模式是 `Session` 上的 `CmdLine { at, query, cursor, selected }`。`cursor` 是查询字符串内的 UTF-8 字节偏移；当前命令字符限制为 ASCII，因此也对应 QML 字符索引。候选过滤、顺序、查询光标和当前选中项由 Rust 计算；QML 只显示 Rust 快照并把按键转回会话。`query` 画在插入点旁的补全层里，不插入文档，因此不改变 `rev`，也不触发排版。

## 外观

命令补全层的提示背景使用独立 GUI 主题 token `color-command-prompt`。它与当前环境高亮分开：行内环境使用 `color-inline-environment-highlight`，块级环境使用 `color-block-environment-highlight`。三者只表示不同的临时交互状态，不写入 `.cdoc`，也不使用文档排版主题的格式值。主题 token 仅在各自的界面调用落地时加入 `Theme.qml`、Rust 主题 schema 和默认/浅色/深色主题，避免保留未使用 token。

命令候选和行内环境可复用 QML `HighlightBackground` Atom，颜色由调用方传入；几何仍由各自的视图能力提供。块级环境与文本、选区共处原生画布场景图，必须由独立 QSG 图层绘制，使用同一主题颜色/圆角 token，不创建覆盖字形的 QML 叠层。命令输入背景占满当前行并为文字留水平内边距，行内环境高亮贴合文本范围，块级/多行环境按布局片段绘制，不套用命令输入的留白。

命令提示颜色只作用于命令查询/补全提示区域，不改变命令实际执行后的环境外观。命令模式可以与光标所在环境同时存在，二者各自使用自己的背景色和几何范围。环境高亮随光标位置自动显示，不需要命令候选。Custom 的用户创建入口尚未设计；当前实现状态见[命令注册表](commands.md#注册表)。

候选列宽根据当前候选内容收缩，单列最大为 105 个逻辑像素；超出列宽的文本仅在当前高亮项中自动循环滚动，不显示滚动条。每轮滚动到末尾后停留 1 秒，复位后再停留 1 秒开始下一轮。滚动是溢出内容的展示动画，不使用轮询定时器。

## 候选可用性

Rust 根据命令实现状态和当前编辑上下文确定候选是否可执行；环境内的嵌套限制也由 Rust 判断，界面不自行推断。空查询时只列出当前可执行的候选，保持注册表顺序；输入非空前缀后，按别名、命令 ID、英文显示名依次匹配，同一优先级保持注册表顺序且每项只出现一次。匹配到的不可执行候选也显示，别名和说明均使用灰色，并禁止执行。不可执行原因或嵌套约束尚未定义的命令仍由对应功能任务明确，不能仅因为位于环境内就一律禁用嵌套。

候选列表包含灰色项时，上下键和点击可以高亮它，以便查看完整名称；Enter 或重复前缀不会执行它，也不关闭查询或改变文档。非空查询的 Tab 可以补全其别名，但不会执行。查询改变后从首项开始高亮；清空查询后立即隐藏不可执行项。注册表仍保留这些命令供非空前缀检索，空查询过滤不删除注册信息。关闭候选面板仅隐藏展示，不改变这些规则。

## 键

这些是已定的交互，不是待选方案。

1. 正文里输入 ASCII `\`，且不在组字中，进入命令模式。普通文字直接输入，不需要“段落”命令。
2. 继续输入字母会过滤候选。匹配顺序是别名、命令 id、label。上下键只移动高亮。
3. 左右键只在查询文本内移动光标；到达查询首尾时停住，不移入正文。前缀 `\` 不属于查询，因此查询为空时光标固定在它之后。
4. Enter 执行高亮的可用候选；没有候选或高亮项不可用时停在命令模式。
5. Tab：查询为空时插入字面 `\` 并退出；查询非空时把当前候选别名补全到查询中，不执行命令。Enter 执行候选；带结构的命令（如分数）执行后把插入点放进第一个空位。
6. 查询非空时再按 `\`：执行当前可用候选，并立刻开始下一条命令；不可用或没有候选时保留查询。
7. 空格无效：不执行，也不插入空格。
8. Esc 进入统一编辑器 Escape 仲裁；命令输入优先级最高，因此会取消并清掉这次查询。查询没进文档，取消没有撤销步。Backspace 在查询开头不删除前缀；查询为空时按 Backspace 会退出。模态对话框和获得焦点的弹出菜单在自己的 UI 焦点范围内先消费 Esc，不传给正文画布。
9. 连续输入 `\\` 得到一个字面 `\`。

公式编辑期间，`\` 交给公式自己的输入，不打开正文命令模式。

## 中文输入

组字中的字符，包括全角反斜线，不进入命令模式。只有普通键盘文本事件里的 ASCII `\` 才进入；IME 提交的字符按正文提交处理，不会追溯触发命令入口。

`、` 后接 Tab 进入命令模式，以及把 `¥` / `￥` 当成 `\` 或公式开头，都是设置项，默认关闭。关闭时这些字符就是正文。开启后，Commit 之后的 Tab 能否稳定识别，要在真实输入法上验证，没有验证之前保持默认关闭。

## 参数

第一版的参数写在别名里：`\section` 就是一级标题，`\table` 就是 2×2。`\frac` 插入公式后进入分子。需要用户再填数字的花括号语法以后单独立项，第一版不做。

## 初始别名

| 输入 | 命令 | 接入 |
| --- | --- | --- |
| `\chapter` `\section` `\subsection` `\subsubsection` | 章、节、小节、小小节 | 010 |
| `\itemize` `\enumerate` | 项目符号 / 编号 | 010 |
| `\math` `\equation` `\align` | 行内公式、单行公式、多行公式 | 011 |
| `\frac` `\sqrt` | 插入对应公式结构 | 011 |
| `\table` | 2×2 表格 | 012 |
| `\newpage` | 分页符 | 后续结构/分页命令 |
| `\newline` | 段内换行 | 009 |
| `\newparagraph` | 插入段落边界；与 Enter 同语义 | 010 |
