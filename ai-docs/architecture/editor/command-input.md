# `\` 命令输入

更新日期：2026-10-30。本文定义命令输入的目标行为与职责边界；实现进度和未完成项见[043 公式模型与编辑](../../task/043-math-model-and-editing.md)。键位总表见[快捷键](../interface/keyboard-shortcuts.md)。

## 状态

命令输入是 `Session` 上的 `CommandLine { at, query, cursor, selected, mode, font_families, preedit }`。普通命令模式只接受 ASCII 命令字符，`cursor` 是查询字符串内的 UTF-8 字节偏移。Enter 接受 `\font` 后进入字体族候选模式；Tab 在普通模式仍只补全别名，不执行候选。字体族模式允许 Unicode 字体名与空格，输入法预编辑和提交都更新该查询，不触碰正文；字体候选来自 024 的本机字体目录，不由 QML 扫描或维护。候选过滤、顺序、查询光标和当前选中项由 Rust 计算；QML 只显示 Rust 快照并把按键转回会话。快照同时提供 Rust UTF-8 光标和 QML 使用的 UTF-16 光标偏移，避免以 JS 字符索引解释 Rust 字节偏移。查询画在插入点旁的补全层里，不插入文档，因此不改变 `rev`，也不触发排版。

## 外观

命令补全层的提示背景使用独立 GUI 主题 token `color-command-prompt`。它与当前环境高亮分开：行内环境使用 `color-inline-environment-highlight`，块级环境使用 `color-block-environment-highlight`。三者只表示不同的临时交互状态，不写入 `.cdoc`，也不使用文档排版主题的格式值。主题 token 仅在各自的界面调用落地时加入 `Theme.qml`、Rust 主题 schema 和默认/浅色/深色主题，避免保留未使用 token。

命令提示背景由 QML 控件绘制。块级和行内环境背景属于文稿画布内容，统一由字形下方的 QSG 环境高亮层绘制；二者复用 QSG 绘制实现，但使用各自的 Rust 布局几何与主题颜色。命令控件的内边距不能套用到环境高亮矩形。三者的分层依据、绘制顺序和复用边界见[画布与交互背景](../interface/canvas-highlighting.md)。

命令提示颜色只作用于命令查询/补全提示区域，不改变命令实际执行后的环境外观。命令模式可以与光标所在环境同时存在，二者各自使用自己的背景色和几何范围。环境高亮随光标位置自动显示，不需要命令候选。

公式编辑状态中的 `\` 交给数学命令查询，不打开正文命令查询；公式结构命令只在允许的数学上下文中执行。Tab 保留公式编辑目标，不向宿主段落插入空格；数学槽位导航由明确的键盘契约定义。

候选列宽根据当前候选内容收缩，单列最大为 105 个逻辑像素；超出列宽的文本仅在当前高亮项中自动循环滚动，不显示滚动条。每轮滚动到末尾后停留 1 秒，复位后再停留 1 秒开始下一轮。滚动是溢出内容的展示动画，不使用轮询定时器。

字体族模式以字体名作为候选主列，不逐项测量整份字体目录来决定弹窗宽度；列表使用虚拟化委托，候选内容仍由 Rust 按当前前缀过滤。空查询显示目录中的字体族，输入 Unicode 前缀后按不区分大小写的前缀筛选；左右移动和 Backspace 按字素簇操作。接受字体族后通过既有 `SetInlineFontFamily` 事务创建或应用 Font 环境。

## 候选可用性

Rust 根据命令描述符和当前编辑上下文确定候选是否可执行；环境内的嵌套限制也由 Rust 判断，界面不自行推断。空查询时只列出当前可执行的候选，保持注册表顺序；输入非空前缀后，按别名、命令 ID、英文显示名依次匹配，同一优先级保持注册表顺序且每项只出现一次。匹配到的不可执行候选也显示，别名和说明均使用灰色，并禁止执行。命令描述符声明支持的上下文及不可执行原因，不能仅因为命令位于环境内就一律禁用嵌套。

候选列表包含灰色项时，上下键和点击可以高亮它，以便查看完整名称；Enter 或重复前缀不会执行它，也不关闭查询或改变文档。非空查询的 Tab 可以补全其别名，但不会执行。查询改变后从首项开始高亮；清空查询后立即隐藏不可执行项。注册表仍保留这些命令供非空前缀检索，空查询过滤不删除注册信息。关闭候选面板仅隐藏展示，不改变这些规则。

## 键

这些是已定的交互，不是待选方案。

1. 正文里输入 ASCII `\`，且不在组字中，进入命令模式。普通文字直接输入，不需要“段落”命令。
2. 继续输入字母会过滤候选。匹配顺序是别名、命令 id、label。上下键只移动高亮。
3. 左右键只在查询文本内移动光标；到达查询首尾时停住，不移入正文。前缀 `\` 不属于查询，因此查询为空时光标固定在它之后。
4. Enter 执行高亮的可用候选；没有候选或高亮项不可用时停在命令模式。
5. 普通命令模式下，Tab 查询为空时插入字面 `\` 并退出；查询非空时把当前候选别名补全到查询中，不执行命令。Enter 接受 `\font` 后进入字体族模式；此模式的 Tab/Enter 接受当前字体族候选。带结构的命令（如分数）执行后把插入点放进第一个空位。
6. 普通命令模式下，查询非空时再按 `\`：执行当前可用候选，并立刻开始下一条命令；不可用或没有候选时保留查询。字体族模式下 `\` 作为查询字符处理，不执行命令。
7. 普通命令模式下空格无效：不执行，也不插入空格。字体族模式允许字体名包含空格。
8. Esc 进入统一编辑器 Escape 仲裁；命令输入优先级最高，因此会取消并清掉这次查询。查询没进文档，取消没有撤销步。Backspace 在查询开头不删除前缀；查询为空时按 Backspace 会退出。模态对话框和获得焦点的弹出菜单在自己的 UI 焦点范围内先消费 Esc，不传给正文画布。
9. 连续输入 `\\` 得到一个字面 `\`。

公式源码草稿编辑期间，`\` 交给公式输入，不打开正文命令补全。数学结构槽位的 `\text{...}` 可进入 Math TextFlow 编辑分支；该分支直接修改 MathTree，并复用正文 TextFlow 的文本、Run 属性、InlineEnvironment 与输入法事务。只有显式源码草稿才在会话状态持有 TeX 文本及临时映射。文本模式下输入 `\math` 是结构命令，不是 LaTeX 源码命令。InlineMath 根层 Math/Text 项在创建或显式源码草稿提交时提升到 Paragraph；分数、脚本等固定槽位内的 TextFlow 保留在槽内，不改变操作数结构。权威边界、位置映射和行为见[数学公式架构](math.md#宿主边界与拆分)。这些操作不打开正文命令候选，也不改变 Equation/Align 的块级宿主。

## 中文输入

组字中的字符，包括全角反斜线，不进入命令模式。只有普通键盘文本事件里的 ASCII `\` 才进入；IME 提交的字符按正文提交处理，不会追溯触发命令入口。

`、` 后接 Tab 进入命令模式，以及把 `¥` / `￥` 当成 `\` 或公式开头，都是设置项，默认关闭。关闭时这些字符就是正文。开启后，Commit 之后的 Tab 能否稳定识别，要在真实输入法上验证，没有验证之前保持默认关闭。

## 参数

命令别名解析成稳定命令 ID 和参数，不以别名文本推断结构类型。`\section` 将 Paragraph block 转为 Section title；段落与标题内容迁移规则见[块环境模型](document-model/document-environments.md)。`\table` 创建 2×2 表格。公式编辑中输入 `\` 打开数学命令查询；`\frac` 插入分数并将插入点放入分子。结构化命令把插入点放入第一个可编辑槽位，不要求用户补齐数字占位符。

## 初始别名

| 输入 | 命令行为 |
| --- | --- |
| `\section` | 创建 Section 块环境 |
| `\chapter` `\subsection` `\subsubsection` | 设置标题层级 |
| `\itemize` `\enumerate` | 创建项目符号或编号列表 |
| `\math` `\equation` `\align` | 插入行内公式、单行公式或多行公式，并进入公式编辑 |
| `\frac` `\sqrt` 等 | 仅在公式编辑中插入对应公式结构并进入第一个空组 |
| `\table` | 插入 2×2 表格 |
| `\newpage` | 插入分页符 |
| `\newline` | 插入段内换行 |
| `\newparagraph` | 插入段落边界；与 Enter 同语义 |
| `\singlecharspace` `\doublecharspace` | 分别插入一个 / 两个字符宽的空格；Tab 等同于 `\doublecharspace`。正文普通 U+0020 空格按排版规则调整为半字宽 |
| `\font` | 打开字体族候选；接受后创建或应用 Font 行内环境 |
| `\firstlineindent` | 设置当前段落首行缩进为 2 个字符宽度 |
