# 文字格式语义

更新日期：2026-11-01。本文定义目标格式语义；当前开发实现与目标载体的差异由[行内与块级环境适配](document-model/inline-and-block-environments.md)标明。节点和字段现状以[文档模型](document-model.md)为准。本文维护格式解析、选择区操作和环境格式化规则；字体候选另见[多文字体系字体选择](font-selection.md)。

## 格式解析

格式状态要区分未指定、显式关闭和设置为某个值。Bold、Italic 环境中，未包裹表示继续继承，`enabled: false` 表示显式关闭；两者不能压成一个布尔值。

### 存储载体

| 属性 | 持久化载体 | 规则 |
| --- | --- | --- |
| Bold、Italic、Font | 行内 `InlineEnvironment` | 有稳定节点身份，可嵌套、拆分并定向解除 |
| Underline | `Run.props.underline` | glyph 装饰直接属性；按语义需要投影为当前行内范围 |
| 段落属性 | `Paragraph.props` / `Paragraph.layout` | 只保存注册表允许的段落值 |

行内持久化载体与统一交互视图的边界见[行内载体与环境视图](document-model/inline-and-block-environments.md)。文档树和字段定义见[文档树与结构](document-model/document-structure.md)。

### 属性解析优先级

属性按项解析：Run/Paragraph 局部显式属性（字体族、粗体、斜体除外）→ EnvironmentNode 有效设置 → 文档全局覆盖 → 主题命名样式 → 应用默认值。`unset` 继续向外回退，不等于 `false`。

环境模板来源的值归入 EnvironmentNode 有效设置层。节点内按 kind 默认模板 → 所选变体 → 实例 `props` 逐层覆盖，再由最近内层环境覆盖外层；未提供的属性不遮蔽外层值。

例如全局字号为 14 pt、Section 默认模板字号为 18 pt、实例未覆盖时，Section 内最终字号为 18 pt。若环境未提供字号，才回退到全局覆盖、主题命名样式和应用默认值。模板引用的命名样式属于环境模板层，不降到普通主题样式回退层。

Run/Paragraph 局部显式属性是直接值（如字号、字色、缩进和段后距），不是命名样式引用。Run 不直接保存字体族、粗体或斜体；局部字体通过 inline `Font` 环境表达。

### 环境树

粗体和斜体各自只用行内 EnvironmentNode 表示，并可互相嵌套。缺少节点表示继承；节点的 `enabled: true|false` 分别显式开启和关闭，缺省 `enabled` 兼容为 true。

文档显式序列化此属性时，在 `requiredFeatures` 中列入 `caret.env.explicit-format-state`。

同类节点仅在 kind、状态、变体、`definitionId`、`props` 和父级样式上下文兼容时合并。相交选区不能形成交叉树边：格式命令在字素边界拆分，并将新环境放入已有环境链内侧，以保留祖先顺序和模板优先级。

一次命令同时创建多种环境时按 Bold → Italic → Font 稳定嵌套。不同命令历史可产生不同但有效的树形，不做会改变有效格式的全树重排。

EnvironmentNode 是权威文档结构，保存时保留节点边界，避免丢失定向 unwrap 和编辑身份。shaping/layout 可以派生扁平有效样式片段，但不能覆盖原环境树。

Run 直接属性保留在 Run 上；engine 可派生交互视图，但不复制格式状态或伪造持久化节点 ID。

切分和合并只更新受影响的行内范围，不因一次格式操作复制整棵文档树。撤销恢复原有节点树、ID、选择和 pending 状态。

### 主题与样式快照

Font 环境可嵌套，内层字体覆盖外层。文档排版主题可定义可复用的 Run/Paragraph 样式；`globalSettings` 选择主题和默认样式，也可覆盖主题值。`.cdoc` 内嵌选中主题的当前格式快照，可保留来源 ID，不依赖外部主题文件持续存在。

主题只维护一个当前格式；载入已知旧主题或快照时迁移到当前结构。外部主题更新不会自动改变已有文档；用户显式更新时才替换快照，并按受影响范围推进 `StyleGeneration`、使对应格式与布局缓存失效。替换前验证所有自定义环境定义及 scope；引用将丢失或改变时拒绝更新，保留旧快照直到用户显式转换相关实例。应用界面主题与文档排版主题相互独立。

选区格式查询返回 `uniform(value)`、`mixed` 或 `unavailable`。混合字体/字号显示“多种格式”，不得拿首字符代表整个选区，也不要把空字符串回写成默认值。

## 选区与待输入格式

- 非空选区修改所覆盖的文字范围，不改文字内容；选区端点先按字素规则向外扩展。相交格式区间在局部边界拆分，新环境放入已有环境链内侧以保留既有模板优先级；仅一次命令同时创建的多个环境按稳定 kind 顺序嵌套。不同命令历史可以留下不同但有效的树形；不得为了生成统一树形而重排已有环境并改变有效格式。测试分别验证正文内容、解析后的有效格式、位置映射和 ID/撤销，不要求语义等价的操作序列生成相同节点树。仅兼容的相邻片段才合并。
- 空选区执行粗体/斜体时，按光标处有效状态切换 pending typing style，下一段已提交输入使用切换后的状态。主题/祖先提供粗斜体而用户显式关闭时，插入或范围格式化生成 `enabled: false` 的 EnvironmentNode；重新开启时生成 `enabled: true`。显式清除局部环境是 unwrap 并恢复继承，不等同于关闭。移动插入点后丢弃旧 pending 值并重新解析新位置上下文。
- 工具栏和弹出控件不能丢失编辑选区。点击颜色选择器后仍作用于原目标范围。
- 粗体/斜体命令采用“统一应用”策略：非空选区只要有任一部分未启用该格式，就将 `enabled: true` 应用到整个选区；仅当整个选区都已启用时才将 `enabled: false` 应用到整个选区。显式 API 设置值与用户点击切换是不同操作。
- Enter 对段落标记的继承、粘贴后的 pending 状态，由命令规格统一定义。
- 正文 Paragraph 中 Enter 新建段落；Shift+Enter 是段内软换行，不触发段间距。块环境标题中的 Enter 规则见[文档模型](document-model.md)。
- 清除字符格式与清除段落格式是不同命令，不连带清除正文或页面设置。

- 首行缩进通过 Paragraph 的 `layout.firstLineIndentChars` 持久化；`\firstlineindent` 在当前段落任意光标位置设置为 2 个基础字号宽度（2 em），实际缩进由 Rust 段落样式解析并交给 Parley 排版。正文中的 Tab 与 `\doublecharspace` 共用插入两个字符宽空格的编辑动作，`\singlecharspace` 插入一个字符宽空格；命令输入期间 Tab 仍用于候选补全。普通 U+0020 空格在布局时采用半字宽排版策略。
- 删除行内格式环境只 unwrap 或删除明确选择的文字范围，不得连带删除外层块级环境。
- 折叠光标位于行内环境时，Mod+Backspace 解除最内层行内环境并保留其内容；嵌套环境按最内层优先，重复使用可逐层解除。没有活动行内环境时，Mod+Backspace 继续交给块环境解除规则；命令输入、IME 组字和普通文本位置不删除正文。

## 颜色与装饰

| 属性 | 语义 | 注意事项 |
|---|---|---|
| 字色 | glyph 前景，可继承、自动、主题色或显式色 | `auto` 不等于固定黑色 |
| 文本高亮 | 高亮语义及其调色板值 | 不与任意 RGB 字符底纹合并 |
| 字符底纹 | 字符范围的背景色 | 可与高亮并存，绘制优先级要明确 |
| 页面颜色 | 文档纸张背景 | 不等于段落底纹；打印输出待定义 |
| 工作区颜色 | 应用界面背景 | 不进入文档，也不打印 |
| 当前环境背景高亮 | 由结构导航定义的临时视图叠加 | 不属于文档格式；详细行为见[结构导航](structure-navigation.md) |
| 下划线 | Run 的 `props.underline` 布尔直接属性 | 单线；颜色跟随该 Run 的最终 glyph 前景 |

“无颜色”“自动”和白色不可混为一谈。主题色引用不能被静默改写为固定 RGB。

下划线保存在 Run 的 `props.underline`，使用 `caret.text.underline` 能力；它不是可嵌套的 EnvironmentNode。043/044 的 engine 适配器将连续下划线范围投影为临时 Inline 语义候选，参与当前环境高亮和 Mod+Backspace；解除只清除目标范围的直接属性，保留文字和其他格式。投影以来源类型与逻辑范围定位目标，不生成持久化节点 ID。

实现只支持单线。线宽和偏移来自 Parley 当前字体 run 的 OpenType 度量；线宽缺失或非正时，以该字体字号的 `1/18` 回退。无法得到有限偏移的片段不生成装饰几何。

装饰几何由 Rust 从最终视觉 glyph runs 导出，覆盖双向顺序、软换行和分页，并携带最终前景色。Qt QSG 仅绘制这些矩形，不参与度量或样式解析。下划线不增加行框高度或段落间距。

## 事务与撤销

每个格式命令先验证整个目标，再以一个文档事务提交。失败不留下部分格式修改，也不改变撤销状态。撤销需恢复格式、选区和 pending 状态。Undo 历史机制由[018](../../task/018-document-lifecycle-history.md)细化。
