# 文字格式语义

更新日期：2026-10-25。数据归属候选由[文档模型](document-model.md)定义；这里记录格式行为。文档树具体表示仍由[020 文档模型决策](../../task/020-document-model-decision.md)核定。

## 格式解析

字符格式至少要区分未指定、显式关闭和设置为某个值。`bold = unset` 表示继续继承，`bold = false` 表示显式关闭，不能把二者压成一个布尔值。

候选解析优先级：文档默认 → 段落样式 → 字符样式 → 外层到内层的行内格式 EnvironmentNode → Run 直接格式。段落格式独立解析。样式名、主题引用、环境作用域和直接格式应能各自保留；不应只存最终字体名或 RGB 值而丢掉继承关系。

粗体、斜体可以各自作为行内 EnvironmentNode 作用于其子 Run，并可嵌套。例如斜体环境里再放粗体环境，最终文字同时斜体和粗体。环境值的 `unset` 继承父作用域，显式 `false` 可在内层关闭对应格式；离开环境后恢复外层值。EnvironmentNode 是权威文档结构，保存时保留节点边界；shaping/layout 可以派生出扁平的有效样式片段，但不能覆盖或丢弃原环境树，以免丢失定向 unwrap 和编辑身份。

选区格式查询返回 `uniform(value)`、`mixed` 或 `unavailable`。混合字体/字号显示“多种格式”，不得拿首字符代表整个选区，也不要把空字符串回写成默认值。

## 选区与待输入格式

- 非空选区修改所覆盖的文字范围，不改文字内容；实现可以在操作后合并属性相同的相邻片段。
- 空选区格式化设置 pending typing style，下一段已提交输入使用该格式。移动插入点后重新解析上下文。
- 工具栏和弹出控件不能丢失编辑选区。点击颜色选择器后仍作用于原目标范围。
- 粗体/斜体的混合值点击策略、Enter 对段落标记的继承、粘贴后的 pending 状态，都要由命令规格统一定义。显式 API 设置值与用户点击切换是不同操作。
- Enter 新建段落；Shift+Enter 是段内软换行，不触发段间距。
- 清除字符格式与清除段落格式是不同命令，不连带清除正文或页面设置。
- 删除行内格式环境只 unwrap 或删除明确选择的文字范围，不得连带删除外层块级环境。

## 颜色与装饰

| 属性 | 语义 | 注意事项 |
|---|---|---|
| 字色 | glyph 前景，可继承、自动、主题色或显式色 | `auto` 不等于固定黑色 |
| 文本高亮 | 高亮语义及其调色板值 | 不与任意 RGB 字符底纹合并 |
| 字符底纹 | 字符范围的背景色 | 可与高亮并存，绘制优先级要明确 |
| 页面颜色 | 文档纸张背景 | 不等于段落底纹；打印输出待定义 |
| 工作区颜色 | 应用界面背景 | 不进入文档，也不打印 |
| 当前环境背景高亮 | 光标所在最内层 EnvironmentNode 的临时视图叠加 | 块级环境高亮容器，行内环境高亮文字范围；不写文档、不打印，也不等同于文字高亮或段落底纹 |
| 下划线 | 字符装饰种类及颜色策略 | MVP 可以只支持单线，但文件读写必须标出降级能力 |

“无颜色”“自动”和白色不可混为一谈。主题色引用不能被静默改写为固定 RGB。若文件含有当前不支持的 underline 样式，需保留原值或显式报告降级，不应宣称无损兼容。

## 事务与撤销

每个格式命令先验证整个目标，再以一个文档事务提交。失败不留下部分格式修改，也不改变撤销状态。撤销需恢复格式、选区和 pending 状态。Undo 历史机制由[018](../../task/018-document-lifecycle-history.md)细化。
