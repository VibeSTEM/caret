# 文字格式语义

更新日期：2026-10-25。数据归属候选由[文档模型](document-model.md)定义；这里记录格式行为。文档树具体表示仍由[020 文档模型决策](../../task/020-document-model-decision.md)核定。

## 格式解析

格式值至少要区分未指定、显式关闭和设置为某个值。以 `underline` 为例，`unset` 表示继续继承，`false` 表示显式关闭，不能把二者压成一个布尔值。

格式属性按属性逐项解析：Run/Paragraph 局部显式属性（字体族除外）→ EnvironmentNode 设置 → 文档全局覆盖 → 主题中的命名样式 → 应用默认值；局部显式属性是直接存于具体 Run/Paragraph 的值（例如字号、字色、缩进、段后距），不是命名样式引用；unset 继续向外回退，不等于 false。默认字体命令设置文档全局默认字体族；局部字体通过 inline `Font` EnvironmentNode 表达，Run 不直接保存字体族。不同字体族的 Font 环境可嵌套并由内层覆盖，同族范围合并或压平。文档排版主题可定义多个可复用的命名 Run/Paragraph 样式，`globalSettings` 选择主题和默认样式，并可覆盖主题值。`.cdoc` 内嵌选中主题的当前格式快照，可记录来源 ID，不依赖外部主题文件持续存在。主题只维护一个当前格式，载入旧主题或快照时迁移到当前结构。应用界面主题与文档排版主题相互独立。粗体和斜体例外，只由其行内 EnvironmentNode 表示，不接受 Run 覆盖。样式名、主题引用、环境作用域和直接格式应能各自保留；不应只存最终字体名或 RGB 值而丢掉继承关系。

粗体、斜体各自只用行内 EnvironmentNode 表示，并可互相嵌套。例如斜体环境里再放粗体环境，最终文字同时斜体和粗体。同类粗体或斜体环境不嵌套，相邻的同类格式作用范围规范化合并；其他语义环境不自动合并。EnvironmentNode 是权威文档结构，保存时保留节点边界；shaping/layout 可以派生出扁平的有效样式片段，但不能覆盖或丢弃原环境树，以免丢失定向 unwrap 和编辑身份。切分和合并必须局部更新受影响的行内范围，不因一次格式操作复制整棵文档树。

选区格式查询返回 `uniform(value)`、`mixed` 或 `unavailable`。混合字体/字号显示“多种格式”，不得拿首字符代表整个选区，也不要把空字符串回写成默认值。

## 选区与待输入格式

- 非空选区修改所覆盖的文字范围，不改文字内容；实现可以在操作后合并属性相同的相邻片段。
- 空选区执行粗体/斜体时，按光标处有效状态切换 pending typing style，下一段已提交输入使用切换后的状态。若在已有格式环境中关闭格式，插入时只局部切分该环境；开启格式则局部创建或合并作用范围。移动插入点后丢弃旧 pending 值并重新解析新位置上下文。
- 工具栏和弹出控件不能丢失编辑选区。点击颜色选择器后仍作用于原目标范围。
- 粗体/斜体命令采用“统一应用”策略：非空选区只要有任一部分未启用该格式，就将格式应用到整个选区；仅当整个选区都已启用时才整体移除。显式 API 设置值与用户点击切换是不同操作。
- Enter 对段落标记的继承、粘贴后的 pending 状态，由命令规格统一定义。
- 正文 Paragraph 中 Enter 新建段落；Shift+Enter 是段内软换行，不触发段间距。块环境标题中的 Enter 规则见[文档模型](document-model.md)。
- 清除字符格式与清除段落格式是不同命令，不连带清除正文或页面设置。
- 删除行内格式环境只 unwrap 或删除明确选择的文字范围，不得连带删除外层块级环境。

## 颜色与装饰

| 属性 | 语义 | 注意事项 |
|---|---|---|
| 字色 | glyph 前景，可继承、自动、主题色或显式色 | `auto` 不等于固定黑色 |
| 文本高亮 | 高亮语义及其调色板值 | 不与任意 RGB 字符底纹合并 |
| 字符底纹 | 字符范围的背景色 | 可与高亮并存，绘制优先级要明确 |
| 页面颜色 | 文档纸张背景 | 不等于段落底纹；打印输出待定义 |
| 工作区颜色 | 应用界面背景 | 不进入文档，也不打印 |
| 当前环境背景高亮 | 由结构导航定义的临时视图叠加 | 不属于文档格式；详细行为见[结构导航](structure-navigation.md) |
| 下划线 | 字符装饰种类及颜色策略 | MVP 可以只支持单线，但文件读写必须标出降级能力 |

“无颜色”“自动”和白色不可混为一谈。主题色引用不能被静默改写为固定 RGB。若文件含有当前不支持的 underline 样式，需保留原值或显式报告降级，不应宣称无损兼容。

## 事务与撤销

每个格式命令先验证整个目标，再以一个文档事务提交。失败不留下部分格式修改，也不改变撤销状态。撤销需恢复格式、选区和 pending 状态。Undo 历史机制由[018](../../task/018-document-lifecycle-history.md)细化。
