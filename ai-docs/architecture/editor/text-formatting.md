# 文字格式语义

更新日期：2026-10-30。节点、字段和持久化归属以[文档模型](document-model.md)为准；本文是格式属性解析、选择区操作和环境格式化行为的唯一详细定义。字体候选另见[多文字体系字体选择](font-selection.md)。

## 格式解析

格式值至少要区分未指定、显式关闭和设置为某个值。以 `underline` 为例，`unset` 表示继续继承，`false` 表示显式关闭，不能把二者压成一个布尔值。只对注册表允许的属性使用直接值：Run 不得直接保存字体族、粗体或斜体；Paragraph 只保存段落属性；EnvironmentNode 只保存其 kind 注册的属性。

格式属性按属性逐项解析：Run/Paragraph 局部显式属性（字体族、粗体、斜体除外）→ EnvironmentNode 有效设置 → 文档全局覆盖 → 主题中的命名样式 → 应用默认值。环境模板来源的值归入 `EnvironmentNode` 有效设置层；节点内部按 kind 默认模板 → 所选变体 → 实例 `props` 的顺序逐层覆盖，再由最近内层环境覆盖外层。模板引用的命名样式也作为环境模板的一部分进入该层，不会降到普通主题命名样式的回退层。例如全局字号为 14 pt、Section 默认模板字号为 18 pt、实例未覆盖时，Section 内最终字号为 18 pt；若环境未提供字号，才回退到全局覆盖，再回退到主题命名样式和应用默认值。EnvironmentNode 未提供的属性不遮蔽外层环境已有的属性。局部显式属性是直接存于具体 Run/Paragraph 的值（例如字号、字色、缩进、段后距），不是命名样式引用；unset 继续向外回退，不等于 false。默认字体命令设置文档全局默认字体族；局部字体通过 inline `Font` EnvironmentNode 表达，Run 不直接保存字体族。不同字体族的 Font 环境可嵌套并由内层覆盖；只有 kind、状态、`definitionId`、`props` 和父级样式上下文均兼容时，范围才可合并。文档排版主题可定义多个可复用的命名 Run/Paragraph 样式，`globalSettings` 选择主题和默认样式，并可覆盖主题值。`.cdoc` 内嵌选中主题的当前格式快照，可记录来源 ID，不依赖外部主题文件持续存在。主题只维护一个当前格式，载入已知旧主题或快照时迁移到当前结构。外部主题文件更新不自动改变已有文档；用户显式更新时才替换文档快照，并按受影响范围推进 `StyleGeneration`、使对应格式与布局缓存失效；替换前须验证所有已引用的自定义环境定义与 scope，引用将丢失或改变时拒绝更新，保留旧快照直到用户显式转换相关实例。应用界面主题与文档排版主题相互独立。粗体和斜体只由其行内 EnvironmentNode 表示，不接受 Run 覆盖；显式关闭的环境表示及相交区间树化规则由 020 定稿。样式名、主题引用、环境作用域和直接格式应能各自保留；不应只存最终字体名或 RGB 值而丢掉继承关系。

粗体、斜体各自只用行内 EnvironmentNode 表示，并可互相嵌套。例如斜体环境里再放粗体环境，最终文字同时斜体和粗体。缺少环境节点表示继承；节点的 `enabled: true|false` 分别显式开启和关闭该属性，不在 Run 存第二份值；缺省 `enabled` 兼容为 true。只要文档显式序列化了该属性，就在 `requiredFeatures` 列入 `caret.env.explicit-format-state`。相同状态、变体、props 和父级样式上下文的同类节点属于冗余，可压平；不同状态的同类节点不是冗余，`on → off → on` 表示局部关闭后重新开启。相交选区不能形成交叉树边，格式命令须在字素边界拆分，并在覆盖范围内将新环境放在已有环境链的内侧，保留已有祖先顺序和模板优先级；一次命令同时创建多种环境时按 Bold → Italic → Font 稳定嵌套。不同命令先后顺序可形成不同树及模板优先级，不做会改变有效样式的全树重排。只在 kind、状态、`definitionId`、`props` 和语义上下文兼容时合并。EnvironmentNode 是权威文档结构，保存时保留节点边界；shaping/layout 可以派生出扁平的有效样式片段，但不能覆盖或丢弃原环境树，以免丢失定向 unwrap 和编辑身份。切分和合并必须局部更新受影响的行内范围，不因一次格式操作复制整棵文档树。

选区格式查询返回 `uniform(value)`、`mixed` 或 `unavailable`。混合字体/字号显示“多种格式”，不得拿首字符代表整个选区，也不要把空字符串回写成默认值。

## 选区与待输入格式

- 非空选区修改所覆盖的文字范围，不改文字内容；选区端点先按字素规则向外扩展。相交格式区间在局部边界拆分，新环境放入已有环境链内侧以保留既有模板优先级；仅一次命令同时创建的多个环境按稳定 kind 顺序嵌套。不同命令历史可以留下不同但有效的树形；不得为了生成统一树形而重排已有环境并改变有效格式。测试分别验证正文内容、解析后的有效格式、位置映射和 ID/撤销，不要求语义等价的操作序列生成相同节点树。仅兼容的相邻片段才合并。
- 空选区执行粗体/斜体时，按光标处有效状态切换 pending typing style，下一段已提交输入使用切换后的状态。主题/祖先提供粗斜体而用户显式关闭时，插入或范围格式化生成 `enabled: false` 的 EnvironmentNode；重新开启时生成 `enabled: true`。显式清除局部环境是 unwrap 并恢复继承，不等同于关闭。移动插入点后丢弃旧 pending 值并重新解析新位置上下文。
- 工具栏和弹出控件不能丢失编辑选区。点击颜色选择器后仍作用于原目标范围。
- 粗体/斜体命令采用“统一应用”策略：非空选区只要有任一部分未启用该格式，就将 `enabled: true` 应用到整个选区；仅当整个选区都已启用时才将 `enabled: false` 应用到整个选区。显式 API 设置值与用户点击切换是不同操作。
- Enter 对段落标记的继承、粘贴后的 pending 状态，由命令规格统一定义。
- 正文 Paragraph 中 Enter 新建段落；Shift+Enter 是段内软换行，不触发段间距。块环境标题中的 Enter 规则见[文档模型](document-model.md)。
- 清除字符格式与清除段落格式是不同命令，不连带清除正文或页面设置。

- 首行缩进通过 Paragraph 的 `layout.firstLineIndentChars` 持久化；`\firstlineindent` 在当前段落任意光标位置设置为 2 个基础字号宽度（2 em），实际缩进由 Rust 段落样式解析并交给 Parley 排版。正文中的 Tab 与 `\doublecharspace` 共用插入两个字符宽空格的编辑动作，`\singlecharspace` 插入一个字符宽空格；命令输入期间 Tab 仍用于候选补全。普通 U+0020 空格在布局时采用半字宽排版策略。
- 删除行内格式环境只 unwrap 或删除明确选择的文字范围，不得连带删除外层块级环境。
- 折叠光标位于行内环境时，Mod+Backspace 解除最内层行内环境并保留其内容；嵌套环境按最内层优先，重复使用可逐层解除。没有活动行内环境时，Mod+Backspace 继续交给块环境解除规则；命令输入、IME 组字和普通文本位置不删除正文。

## 颜色与装饰

| 属性 | 语义 | 注意事项 |
|---|---|---|
| 字色 | glyph 前景，可继承、自动、主题色或显式色 | `auto` 不等于固定黑色 |
| 文本高亮 | 高亮语义及其调色板值 | 不与任意 RGB 字符底纹合并 |
| 字符底纹 | 字符范围的背景色 | 可与高亮并存，绘制优先级要明确 |
| 页面颜色 | 文档纸张背景 | 不等于段落底纹；打印输出待定义 |
| 工作区颜色 | 应用界面背景 | 不进入文档，也不打印 |
| 当前行内/块环境背景高亮 | 当前结构或行内格式范围的临时视图叠加 | 不属于文档格式；绘制与范围优先级见[画布与交互背景](../interface/canvas-highlighting.md) |
| 下划线 | Run.props 的 `underline` 直接属性；缺省表示没有直接值 | 当前只接受 `true`/`false`；开启为单线，颜色跟随该 Run 的最终 glyph 前景 |

“无颜色”“自动”和白色不可混为一谈。主题色引用不能被静默改写为固定 RGB。下划线持久化为 `Run.props.underline: true|false`：字段缺省表示没有直接值；M0 尚未定义环境、全局或主题中的下划线样式来源，因此最终默认关闭。`true` 表示单线装饰，`false` 表示显式关闭；装饰颜色跟随 Run 最终 glyph 前景。折叠光标位于显式下划线 Run 中、且不在行内环境中时，同一行内背景层高亮该 Run 的实际文字范围；环境高亮优先，背景仍是临时视图状态。文档节点的下划线直接属性仅允许存于 Run。文档只要含有该键（包括显式 `false`）就声明 `caret.text.underline` 必需能力。当前读取器遇到非布尔值时保留原值并进入只读安全预览、展示不支持能力诊断且禁用写入；当前读取器检测到该属性缺少必需能力标记时也拒绝编辑和保存。实现只支持单线；线宽和偏移来自 Parley 当前字体 run 的 OpenType 度量，线宽缺失或非正时以该字体字号的 `1/18` 回退。无法得到有限偏移的片段不生成装饰几何。装饰几何由 Rust 从最终视觉 glyph runs 导出，覆盖双向顺序、软换行和分页，并携带最终前景色；Qt QSG 仅绘制这些矩形，不参与度量或样式解析。下划线不增加行框高度或段落间距。

## 事务与撤销

每个格式命令先验证整个目标，再以一个文档事务提交。失败不留下部分格式修改，也不改变撤销状态。撤销需恢复格式、选区和 pending 状态。Undo 历史机制由[018](../../task/018-document-lifecycle-history.md)细化。
