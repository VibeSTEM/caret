# 剪贴板

更新日期：2026-11-21。本页是系统剪贴板的数据格式、片段形状、格式回退、粘贴识别和失败行为的唯一架构权威。命令注册与当前实现状态见[命令](commands.md)；选区范围由[块宿主交互协议](document-model/block-interaction.md)定义；MathTree 与 TeX 子语言转换见[数学公式](math.md)。

## 目标与职责边界

Caret 剪贴板在 Caret 文档模型片段之上提供应用间传输。Caret 专用载荷保留规范节点和公式树；text/plain 为其他应用提供可读文本与规范 TeX。两种格式来自同一已选范围，不由 Qt 分别推导。

Qt 只负责系统剪贴板的 MIME 读写和读取优先级。Rust 持有选区权威，负责裁切规范节点、片段验证、节点身份重映射、TeX 转换以及一次性粘贴事务。剪贴板层不维护第二份选区、不创建通用文档交换 AST，也不执行任意 TeX 宏。

## Caret 专用片段

MIME 为 `application/vnd.caret.fragment+json`。JSON 信封携带 schema 版本和带标签的片段形状；各变体直接承载裁切后的规范 Paragraph、Block、Inline、MathTree 或 Align 节点，仅额外保存传输所需的边界元数据。

| 形状 | 内容 | 插入规则 |
| --- | --- | --- |
| Inline | 单个裁切 Paragraph 与段落首尾边界标记 | 只可粘贴到 Paragraph 插入位置，作为行内内容插入 |
| Blocks | 按文档顺序排列的规范 Block 序列；部分范围的首尾 Paragraph 保留为裁切 Paragraph，并带段落边界标记 | 按共享宿主边界插入；首尾裁切 Paragraph 与目标位置的前后段落前缀/后缀按标记合并 |
| Math | 选中的连续 MathFlow 裁切成有效 MathTree，或保留完整 Equation/Align；记录来源宿主种类 | 只可插入到兼容的数学宿主；不兼容时明确拒绝 |

MathTree/MathText 内部选区按其局部范围裁切；若无法构造有效 MathTree 片段，则复制失败，不退化为整个公式或 U+FFFC。粘贴前验证版本、模型和所有节点；为被复制节点及数学子树重建身份，避免源与目标文档 ID 冲突。

未知版本、损坏 JSON、不支持节点、身份重映射失败或片段与目标宿主不兼容时，整次操作原子拒绝。不得丢弃 Caret 载荷后改用 text/plain 粘贴，也不得改变文档、焦点、选区、历史或原系统剪贴板。

## 纯文本回退

同一次复制还生成 text/plain：

- 行内公式使用 `\(...\)`。
- Equation 使用 `\[...\]`。
- Align 使用 `\[\begin{aligned}...\end{aligned}\]`。
- 普通文本和块边界按阅读顺序呈现；已支持的文本格式可以退化为可读文本，但不得输出 U+FFFC 作为对象替身。

公式片段通过[数学公式](math.md)中的 checked TeX serializer 生成。若已知数学语义或扩展字段不能被安全表达，serializer 返回结构化损失，复制返回结构化错误且不覆盖系统剪贴板；桌面端的用户可见提示由任务 105 接入。text/plain 是给其他应用使用的可读回退，不承诺保留 Caret 专有格式；Caret 间保真由专用 MIME 提供。

## 纯文本粘贴

只有没有 Caret 专用载荷时才解析 text/plain。识别显式、未转义且闭合的数学定界符，不猜测普通文本为公式：

1. 先匹配 `\[...\]`；内容完整包裹 `\begin{aligned}...\end{aligned}` 时构造 Align，否则构造 Equation。
2. 再识别 `\(...\)` 行内片段。
3. `$...$` 仅在去除首尾空白后占据全部剪贴板文本时识别，避免把价格内容猜成公式。

仅当能确定完整片段边界时转换。解析失败、超限、未闭合定界符或混合文本中的边界有歧义时，整段按普通文本处理，不部分插入公式。混合 `\(…\)` 文本若含硬换行，整段按普通文本粘贴（行内插入路径不承载换行，由普通粘贴拆段）。解析使用[数学公式](math.md)规定的受限语法；不执行 TeX 宏、包或命令。

## 事务与状态

一次粘贴最多产生一个 Rust 文档事务和一个 Undo 单元。成功后按共享宿主协议设置折叠后的有效插入位置；失败保留文档、焦点、选区、generation 和历史。重做应恢复同一结构及内容。
