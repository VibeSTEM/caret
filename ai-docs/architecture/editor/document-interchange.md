# 文档格式导入与导出

更新日期：2026-10-29。

## 规范模型与适配边界

`caret-doc` 的版本化文档树是 Caret 唯一的规范 AST，`.cdoc` 是其原生持久化格式。不要再设计一个缺少格式语义的通用 AST，作为 `.docx`、`.tex`、`.md` 和 Caret 之间的中转模型；这会形成第二套长期数据模型，并迫使各格式都退化到共同子集。

每种外部格式有独立的读写适配器。导入器将格式解析为该格式能表达的结构，再映射到规范文档树；实现复杂格式时可以在适配器内部建立短生命周期的源格式 IR，用于包关系、样式继承、宏/环境等映射，但 IR 不跨格式共享、不写进 `.cdoc`，也不替代规范模型。简单格式可以边解析边构造文档树。导出器从规范文档树生成目标格式自己的结构。

```text
.docx / .tex / .md
        │
        ├── 格式专属解析器 / 可选的短生命周期源 IR
        │
        ▼
Caret 规范文档树（caret-doc） ──► .cdoc
        │
        └── 格式专属导出器 ──► .docx / .tex / .md
```

转换边界返回结构化诊断：源位置、映射出的文档位置（若可得）、不支持的结构、发生的简化及建议操作。不得静默丢弃内容或格式。导入在临时文档中完成解析和验证并展示转换摘要后，才允许安装为新文档会话。若当前会话为 Edited，先复用 018 定义的 Save / Don't Save / Cancel 关闭确认；用户取消、保存取消或保存失败时保留当前会话。导入请求携带会话 generation，迟到结果不得覆盖已切换或更新的会话。导出只写目标文件，不改变原 `.cdoc` 的路径、标题或保存状态。

## 保真与失败规则

- 导入保留可映射的结构与语义；目标模型无法表达的源特性必须列入转换报告，并在用户确认接受降级后才生成结果。
- 对无法安全映射或可能改变内容含义的构造，拒绝导入并保留源文件；不得把未知结构伪装成普通文本后宣称无损。
- 导出采用同一规则：报告目标格式不支持的结构、样式、元数据和功能；用户确认后才写出降级副本。导出不改写当前文档。
- 首版不承诺与源应用逐像素、逐页一致，也不承诺外部格式往返逐字节相同；只对文档结构与明确支持的语义定义往返契约。
- 文件读写需限制解压后大小、嵌套深度、节点数和资源数量；从文件导入不执行代码、宏、脚本或外部链接。

## 格式范围

### `.md`

采用明确命名的 CommonMark 基线和 Caret 支持的扩展集合。Markdown 按块与行内结构组织；首版只映射已有规范模型能表达的段落、标题、强调和列表。链接、引用块、代码块、表格、数学公式、图片及扩展语法暂不列入首版支持范围，直到目标语义与节点能力有明确实现；导入时必须报告或拒绝，不能去掉结构后伪称无损。表格与数学扩展分别依赖 011/012 完成后再接入。导出只生成所选方言的语法，不通过隐式插件扩充输出。

### `.tex`

Caret `.tex` 交换范围是文档结构和已支持公式的安全子集，不是通用 TeX 执行环境。解析不运行任意宏、shell escape、外部程序或用户包；宏包、用户宏及无法解析的命令需要转换诊断，必要时拒绝。`latex-rust` 用于数学表达式/数学盒，不是完整 LaTeX 文档解析器；完整文档的章节、段落、列表、表格等由独立的 TeX 子集适配器处理。

### `.docx`

`.docx` 是包含多个部件及关系的 Open XML 包，不是单个扁平 XML 文档。导入器需要从包关系发现文档部件，再将段落、Run、样式、编号、表格、节等映射到 Caret 模型。外部关系不得自动访问。复杂样式继承、修订、批注、脚注、页眉页脚、嵌入对象等须逐项声明支持状态；不在首版范围的内容进入转换报告，不得静默丢弃。
