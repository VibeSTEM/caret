# 页面与段落排版

更新日期：2026-10-25。版式属性属于文档；页、行和视觉片段是派生布局。文档模型结构由 [020](../../task/020-document-model-decision.md) 定稿，增量策略见[增量排版](incremental-layout.md)。

## 纸张、节与单位

页面尺寸、方向和上下左右边距是文档属性，归 `PageSection` 管理。它与可嵌套的内容 `EnvironmentNode` 是不同概念；M0 恰用一个 `PageSection` 覆盖整份正文，不支持分节范围。默认是 A4 纵向、四边各 72 pt；首版纸型仅 A4/A3，方向只交换页面宽高，不旋转页面图像。边距为有限非负 pt 值，左右边距之和必须小于页面宽，上下边距之和必须小于页面高；零边距有效。自动分页和显式分页必须分开：自动分页不写入文档；显式分页符是文档内容，分节节点留待后续设计。页面边缘、工作区留白、页间距、阴影、缩放和 DPR 属于视图，不得回写物理页面尺寸。

物理长度用 pt：`1 in = 72 pt = 25.4 mm`。例如 A4 是 210 × 297 mm，即约 595.276 × 841.890 pt；A3 是 297 × 420 mm，即约 841.890 × 1190.551 pt。内部保留足够精度，界面显示到 0.01 mm 时误差不超过 0.005 mm。其他交换格式只在边界换算并定义舍入误差。几何值保存在 `PageSection.props` 的 `paperSize`、`orientation` 和 `marginsPt` 键；旧文件缺失这些可选键时按默认几何解释，未知键保留，已知键类型错误或几何无效时拒绝文档。

方向交换页面宽高，不是旋转页面图像。M0 正文宽高为页面尺寸扣除相应边距；无效数值、非有限值、边距耗尽页面都应拒绝且保持文档和 Undo 状态不变。装订线与页眉/页脚距离不属于 M0 页面几何，后续单独设计，加入后仍与正文边距分开。

## 行框、字形和行距

每行至少区分行框高度、baseline 和 glyph ink bounds。自然行高来自所有文字片段的字体 ascent/descent、基线偏移及行内对象，空段落使用段落标记度量，不能因无 glyph 而零高。

行距是有单位/语义标签的段落属性，而非单一 `lineHeight` 数字。自然文字高度由行内所有塑形字体的最大 ascent、最大 descent 与最大 leading 之和构成；额外行高在 ascent/descent 外平均分配，baseline 位于 ascent 加一半额外行高处。空段用当前段落标记样式塑形段落标记字形以取得真实字体度量，但不把测量字符写入正文：

| 语义 | 候选值 | 计算约束 |
|---|---|---|
| Multiple | 正的比例，如 1.0、1.15、1.5、2.0 | 自然文字高度乘比例；行内对象所需高度是不可缩小的下限 |
| AtLeast | 最小 pt 高度 | 取自然行高、对象所需高度和指定下限的最大值 |
| Exactly | 固定 pt 行推进高度 | 不静默扩成 AtLeast；字形或对象可按明确策略溢出 |

界面可有单倍、1.5 倍、双倍、多倍、最小值、固定值六个入口，但数据模型只存上述有类型的三种语义。字号并不等于自然行高。上标、下标、公式、图片和段落标记必须进入度量策略。

默认预设下，Multiple 和 AtLeast 将组合后的行框垂直居中于文本/对象度量范围；Exactly 高于自然需求时同样居中，低于自然需求时按 OOXML 固定行高语义让内容在行框底部对齐并从顶部裁切。不得把固定值偷偷改成 AtLeast。行框、glyph ink bounds 和页面裁剪分开表示。

## 默认排版配置与期刊模板

新建 `.cdoc` 默认使用已选的段落默认配置，而不把 OOXML 用作文档存储格式：正文行距为 1.15 倍，段前 0 pt、段后 10 pt；启用孤行/寡行控制。正文段落默认不启用与下段同页、段落不拆分或段前分页；标题样式可单独配置与下段同页。该配置参考公开的常见文字处理器默认模板参数；这些数值不是 ECMA-376 强制所有文档使用的值，资料出处和格式映射记录在[标准研究](../../research/008-office-open-xml-spacing-pagination.md)。

参考数值保存在独立的 `crates/caret-doc/resources/layout-themes/default.json` 预设中，并在构建时嵌入；新建文档和缺少全局段落样式的旧文档从该预设取默认值。文档将完整生效值保存在 `.cdoc` 的 `globalSettings.paragraphLayout`，段落可在 `layout` 字段只覆盖需要变化的属性。布局器把这些整数厘点值解析为自己的行距类型和 pt 值，并消费孤行/寡行、与下段同页、段落不拆分和段前分页约束。修改应用内置预设不会静默改变已保存文档的效果。其他期刊预设放在同一目录并映射到相同的 `.cdoc` 模型；不提供笼统的“通用 LaTeX 默认”，因为 LaTeX 的行距和分页由文档类、字号、字体、宏包及规则共同决定。

## 段间距和分页

段前/段后是独立物理长度；默认预设为段前 0 pt、段后 10 pt，软换行不引入段间距。相邻段落按选定配置计算净段距，并通过 OOXML fixture 核对行推进、基线距离和段落间净空白的映射；不能仅从字段名推导布局算法。默认预设启用孤行/寡行控制；与下段同页、段落不拆分与段前分页是独立段落分页属性。显式分页符按文档流事件每次推进一页；开头、连续和末尾的显式分页符都会保留对应空页。一个段落跨页时，分页结果引用同一段文本与范围，不复制段落内容。

分页消耗行推进高度和生效段间距。若单行推进高度超过版心高度，或对象高于整页版心，该行仍只放置一次并在页面上溢出，不能不断创建空页；固定行距下溢出的 ink 不悄悄改变分页高度。版心、字体度量、行距、段间距和分页规则改变时，失效范围要从对应段落扩展到受影响的后续页。

默认纸型与页边距已由 023 定为 A4 纵向、四边各 72 pt。字体族由文档主题和系统字体回退决定；字号是独立的样式输入，由全局/主题解析后传入布局器。默认段落预设只决定行距、段距和段落分页属性，不隐式切换纸张几何。期刊模板可显式替换该配置。装订线、页眉/页脚距离不属于 M0；页面边长由 A4/A3 固定，不接受任意尺寸。

## `caret-layout` 模块边界

布局流程按昂贵计算和失效范围拆成独立阶段；文档模型只存输入属性，不存缓存页或预排版行：

| 模块 | 职责 | 不负责 |
|---|---|---|
| `font_selection` | 预编译 `.cdoc` 的默认字体、CJK、脚本及脚本内语言偏好；对已分析的 Script/BCP 47 语言上下文给出候选字体族 | 扫描字体目录、分析 Unicode 字符、替代 Fontique 的字形覆盖率查询 |
| `shaping` | 展平段落行内结构、按 Run/Paragraph 语言生成 ICU 边界，并提供 Parley 样式范围输入 | 自行做字体选择、glyph shaping、cluster 生成、行断或分页 |
| `shaping/unicode.rs` | 复用 ICU4X 与 `unicode-segmentation` 生成固定数据版本的断行/字素边界，应用 Caret 选择的语言 tailoring | 字体查询和字形塑形 |
| `paragraph/parley.rs` | 构建并保留唯一 Parley 高层 `Layout`；提供字素安全的光标、命中和选区适配，并把 Parley 行结果映射到 Caret 行框 | 文档属性持久化、字体文件目录扫描或分页 |
| `line_metrics` | 按文档行距规则从 Parley 字体度量计算 Caret 行框和 baseline | 重复执行字体 shaping |
| `pagination` | 消费段落行与 `PageSection` 可用高度，应用段间距/显式分页，输出稳定 Paragraph ID、行范围和页内偏移 | 复制正文、改写文档树或拥有长期缓存 |
| 增量缓存 | 后续由 013 定义缓存键和脏范围传播；字体目录代际与文档 revision 是输入版本 | 混入上述纯计算阶段的隐式全局可变状态 |

段落只构建一次 Parley `Layout`，由它同时提供分页行范围、绘制所需 glyph runs 以及双向视觉交互几何。不能把 UTF-8 字节顺序当作视觉左右顺序。Caret 在 Parley Layout 外保留其文档行距和页级分页策略；Qt scene graph 绘制适配应复用该 Layout 的字体实例、glyph ID 和位置，不能再把正文送入 Qt 文本引擎独立换行。Unicode grapheme、bidi 和 line-break conformance 由固定 corpus 覆盖；集成阶段还需对平台字体差异、行尾空白和未来行内对象作专项验证。
