# 页面与段落排版

更新日期：2026-10-25。版式属性属于文档；页、行和视觉片段是派生布局。文档模型结构待 [020](../../task/020-document-model-decision.md)确认，增量策略见[增量排版](incremental-layout.md)。

## 纸张、节与单位

页面尺寸、方向、上下左右边距、装订线和页眉/页脚距离是文档属性，归 `PageSection` 管理。它与可嵌套的内容 `EnvironmentNode` 是不同概念；MVP 可只提供一个 `PageSection`。自动分页和显式分页必须分开：自动分页不写入文档；显式分页符/分节符是文档内容。页面边缘、工作区留白、页间距和阴影属于视图。

物理长度用 pt：`1 in = 72 pt = 25.4 mm`。例如 A4 是 210 × 297 mm，即约 595.276 × 841.890 pt；A3 是 297 × 420 mm，即约 841.890 × 1190.551 pt。内部保留足够精度，界面显示时再舍入。其他交换格式只在边界换算并定义舍入误差。

方向交换页面宽高，不是旋转页面图像。可打印正文宽高为页面尺寸扣除相应边距和装订线；无效数值、非有限值、边距耗尽页面都应拒绝且保持文档和 Undo 状态不变。页眉/页脚距离与正文边距分开。

## 行框、字形和行距

每行至少区分行框高度、baseline 和 glyph ink bounds。自然行高来自所有文字片段的字体 ascent/descent、基线偏移及行内对象，空段落使用段落标记度量，不能因无 glyph 而零高。

行距是有单位/语义标签的段落属性，而非单一 `lineHeight` 数字：

| 语义 | 候选值 | 计算约束 |
|---|---|---|
| Multiple | 正的比例，如 1.0、1.15、1.5、2.0 | 与自然文字行高组合；行内对象仍须容纳 |
| AtLeast | 最小 pt 高度 | 取自然行高、对象所需高度和指定下限的最大值 |
| Exactly | 固定 pt 行推进高度 | 不静默扩成 AtLeast；字形或对象可按明确策略溢出 |

界面可有单倍、1.5 倍、双倍、多倍、最小值、固定值六个入口，但数据模型只存上述有类型的三种语义。字号并不等于自然行高。上标、下标、公式、图片和段落标记必须进入度量策略。

Exactly 小于字形 ink 高度时，行推进保持固定；是否溢出、是否提示及如何裁剪属于产品决策。禁止布局器偷偷把固定值改成最小值。页边裁剪、行框和 glyph ink 裁剪分开处理。

## 段间距和分页

段前/段后是独立物理长度；软换行不引入段间距。相邻段间距合并规则、新页首段段前间距、同页/孤行控制、显式分页符边界都需要有明确测试。一个段落跨页时，分页结果引用同一段文本与范围，不复制段落内容。

分页消耗行推进高度和生效段间距。固定行距下溢出的 ink 不悄悄改变分页高度。版心、字体度量、行距、段间距和分页规则改变时，失效范围要从对应段落扩展到受影响的后续页。

具体规则（Normal 预设、默认字号、行距、页边距、页眉距离、页面边长限制）仍是产品待决策，不能把参考实现的默认值直接复制成 Caret 的承诺。
