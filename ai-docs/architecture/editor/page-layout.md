# 页面与段落排版

更新日期：2026-10-26。本文定义 `.cdoc` 页面几何、行框、段落间距和分页的产品规则，以及布局层的职责。文档属性属于 `Document`；页、行和屏幕上的字形位置均为派生结果。文档树与样式归属见[文档模型](document-model.md)，缓存失效见[增量排版](incremental-layout.md)，默认数值见[默认排版预设](../../../crates/caret-doc/resources/layout-themes/default.json)和[008 标准研究](../../research/008-office-open-xml-spacing-pagination.md)。

## 页面几何与单位

页面尺寸、方向和四边边距由 `PageSection` 管理，与内容环境 `EnvironmentNode` 无关。M0 使用一个 `PageSection` 覆盖整份正文；分节范围和文档内分节符留待后续设计。

物理长度统一使用 pt：`1 in = 72 pt = 25.4 mm`。M0 纸型为 A4 或 A3，默认 A4 纵向、四边各 72 pt。方向只交换页面宽高，不旋转页面图像。页面边长扣除左右、上下边距后得到版心；边距必须是有限非负值，且对边之和小于对应页面边长。零边距有效。装订线、页眉和页脚距离不属于 M0 页面几何。

A4 为 210 × 297 mm，约 595.276 × 841.890 pt；A3 为 297 × 420 mm，约 841.890 × 1190.551 pt。内部保留足够精度；界面显示到 0.01 mm 时，换算误差不超过 0.005 mm。交换格式只在边界换算并明确定义舍入。几何保存在 `PageSection.props` 的 `paperSize`、`orientation`、`marginsPt` 中。旧文件缺少这些可选键时使用默认几何；未知键保留；已知键类型错误、非有限值或无效几何时拒绝文档，且不改变文档和 Undo 状态。

页面边缘、工作区留白、页间距、阴影、缩放和 DPR 是视图属性，不得写回物理页面尺寸。自动分页是派生结果，不写入正文；显式分页符属于文档内容。开头、连续和末尾的显式分页符都保留对应空页。

## 行框、基线与字形

排版需要分别计算三件事：

| 概念 | 含义 | 影响 |
| --- | --- | --- |
| 行框与行推进 | 行占用的布局高度，以及下一行/段落从哪里开始 | 行距、段距、分页 |
| 主基线 | 当前行的基线参照 | 不同脚本及字号的字形如何对齐 |
| 字形 ink bounds | 字形实际绘制的范围，可能超出 advance 或行框 | 绘制、裁剪和溢出 |

Caret 采用 [Microsoft Learn 的 OpenType BASE 表说明](https://learn.microsoft.com/en-us/typography/opentype/spec/base)作为不同脚本基线对齐的依据。该页面是 Microsoft 发布的公开 OpenType 技术规范文档。BASE 模型以一个 script/size 的 dominant run 为参照，其他脚本基线相对于它定义；字体提供的是建议基线，排版客户端仍可采用自己的基线策略。BASE 还可按脚本、语言系统或特性提供字形范围度量。

Caret 不把全局默认拉丁字体的 ascent 当成所有脚本的共同基线。dominant run 按段落的有效语言确定：Paragraph 语言优先，其次文档默认语言；两者均未给出脚本时，使用段落中第一个强脚本。该选择在软换行之间保持不变，避免某行开头恰好是另一脚本就改变整段基线。dominant run 的字号和字体取对应的段落默认文本样式。阿拉伯语段落因此以 Arab 脚本为参照；混排段落中的阿拉伯语、CJK、拉丁、数学和字体回退则按各自脚本 BASE 基线相对于该参照对齐。

文档的行推进网格由行距规则确定，脚本基线偏移只调整对应 run 的 glyph 位置，不得改变同一段落各行的推进间距。标点等 Common/Inherited 字符继承相邻强脚本；若两侧没有强脚本则回退到段落有效语言。单独插入一个全角符号不应改变 dominant run，也不应把既有文字或后续行整体推移。字体缺少所需 BASE 数据时，布局器使用确定的字体度量回退，不能默默套用拉丁基线。

dominant run 的选择、Common/Inherited 字符归属和 BASE 缺失时的回退必须确定、可测试。实现需同时保证：行框高度按真实字形和对象范围计算；段落行推进遵循所选行距；每个 run 根据主基线和对应脚本的 BASE 度量得到字形基线偏移。BASE 对齐不能缩小行框、丢弃 ink 范围或掩盖裁剪/溢出。

自然行高容纳该行所有字体的 ascent、descent、leading 和行内对象；空段落按段落标记样式的真实度量排版，不向正文插入测量字符。不同脚本行的字形基线可以依据 BASE 产生脚本相关偏移，但这不能改变行推进规则。更大的字体、回退字形、组合附标、公式和图片必须参与行框/溢出计算，不得被固定的默认字号锚点压入上一行。

## 行距与默认值

行距是有语义和单位的段落属性，不是单一无类型的 `lineHeight`。文档模型保存整数厘点或明确的比例；布局器在内部换算为 pt。字号不等于行高。段落行距首版支持：

| 类型 | 语义 |
| --- | --- |
| `Natural` | 按行内文字与对象的实际度量计算自然行高 |
| `Multiple` | 自然行高乘正比例；行内对象所需高度仍是不可缩小的下限 |
| `AtLeast` | 行高不小于自然行高、对象所需高度和指定下限 |
| `Exactly` | 行推进保持指定高度；字形或对象允许绘制溢出并按页面/行框裁剪，不偷偷扩成 `AtLeast` |

界面可提供单倍、1.5 倍、双倍、多倍、最小值和固定值入口；持久化值使用上述有类型语义。自然行高由字体度量的最大 ascent、最大 descent、最大 leading 与行内对象所需高度共同决定。Multiple 和 AtLeast 高于内容需求的额外高度在内容上、下方平均分配；Exactly 高于内容需求时内容垂直居中，低于内容需求时保持固定推进高度、按内容 descent 将内容底部对齐，并允许顶部 ink 溢出后由行框裁切。字号或 BASE 脚本偏移不得改变这些行距定义；发生内容超框时必须保留溢出状态，不能通过移动字形或错误度量标成未溢出。

新建 `.cdoc` 使用内置默认排版预设：正文行距 1.15 倍、段前 0 pt、段后 10 pt，并启用孤行/寡行控制。正文默认不启用“与下段同页”“段落不拆分”或“段前分页”；标题样式可单独启用与下段同页。默认预设文件位于 `crates/caret-doc/resources/layout-themes/default.json`，新建文档和缺少全局段落样式的旧文档从该预设取值。文档将实际生效的全局值保存在 `.cdoc` 的 `globalSettings.paragraphLayout`，段落只覆盖不同于全局值的属性。修改应用默认预设不静默改变已有文档。

排版数值参考常见文字处理器默认模板，并用 OOXML fixture 核对具体数值到行推进、基线距离和段落净空白的映射。OOXML 是验证数值映射的交换规范，不是 `.cdoc` 存储模型，也不意味着这些数值是 OOXML 强制的全局默认值。文档默认效果参考 Microsoft Word 的常见默认配置；不同期刊通过同一模型的独立排版预设提供。LaTeX 没有唯一通用的行距与分页默认值，因此不定义笼统的“LaTeX 默认”。来源与映射记录见[008 标准研究](../../research/008-office-open-xml-spacing-pagination.md)。

## 段间距与分页

段前/段后间距是独立物理长度。默认段前 0 pt、段后 10 pt；软换行不引入段间距。相邻段落按当前预设的规则计算净间距，不可只根据字段名推导算法。孤行/寡行、与下段同页、段落不拆分和段前分页是互相独立的段落分页属性。

分页器消费行推进高度、有效段间距、版心高度和显式分页符。跨页段落引用同一段文本与范围，不复制正文。若单行推进高度超过版心，或对象高于整页版心，该行只放置一次并允许溢出，不能为同一行不断创建空页。Exactly 下溢出的 ink 不得悄悄增加分页高度。版心、字体度量、基线对齐、行距、段距和分页规则改变时，失效范围从受影响段落扩展至后续受影响页面。

## 布局阶段与职责

段落仅塑形一次。Parley 的 `Layout` 是 glyph shaping、行切分和双向视觉交互几何的权威来源；Caret 在其结果上计算文档行框、页内偏移和分页。Qt scene graph 复用 Rust 交付的字体实例、glyph ID 和位置绘制，不再将正文交给 Qt 文本引擎单独换行。UTF-8 文档顺序不能直接当作屏幕上的视觉左右顺序。

| 阶段 | 职责 | 不负责 |
| --- | --- | --- |
| `font_selection` | 根据默认字体、CJK、Unicode Script 和 BCP 47 语言偏好生成候选字体 | 扫描字体目录、分析字符、替代 Fontique 字形覆盖查询 |
| `shaping` | 展平段落行内结构，生成语言相关边界并提供 Parley 样式范围 | 自行选字体、塑形 glyph、生成 cluster、断行或分页 |
| `shaping/unicode.rs` | 复用 ICU4X 与 `unicode-segmentation` 生成固定数据版本的断行/字素边界，并应用语言 tailoring | 字体查询或 glyph shaping |
| `paragraph/parley.rs` | 构建并保留 Parley `Layout`；适配字素安全光标、命中、选区和视觉行结果 | 文档持久化、字体目录扫描或分页 |
| `line_metrics` | 消费字体/对象度量与行距语义，计算行框、主基线和溢出 | 重复塑形 |
| `pagination` | 消费段落行、`PageSection` 版心、段距及显式分页，输出页片段和页内偏移 | 复制正文或改写文档树 |

布局快照必须带文档 revision、样式代际、字体目录代际及视口/缩放所需的版本信息；过期的异步结果不得覆盖更新后的布局。缓存按失效范围复用塑形、基线度量和分页结果，不能为每次按键重复扫描字体目录或重塑未受影响段落。具体缓存键、脏范围传播和性能约束见[增量排版](incremental-layout.md)。Unicode grapheme、bidi、断行和脚本基线对齐需由固定 corpus 覆盖，并通过跨脚本、回退字体和字号差异用例验证。
