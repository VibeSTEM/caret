# 结构导航

更新日期：2026-10-24。键位见[快捷键](../interface/keyboard-shortcuts.md)。

## 什么算结构

| 单元 | 怎么认 | 边界 |
| --- | --- | --- |
| 段落 | 一个 `Para` | 整段 |
| 标题 | 解析后的大纲级别小于 9 | 标题段本身；当作一节时，延伸到下一个同级或更高级标题之前 |
| 列表项 | 段落带编号引用 | 一项一段；同一编号的连续段是一个列表 |
| 公式 | 内联对象里的数学树 | 对象本身；内部用 `MathPos` |
| 表格 | `Table` | 表、行、单元格、单元格里的块 |

字符级的粗体、颜色不算结构。导航不为它们建节点。

## 索引

`caret-structure` 只读 `Document`。

- 节点按文档序排列，记下种类、路径、级别和范围。
- 每个顶层块记下生成它时的 `rev`。只有 `rev` 变了的块重算，插入和删除时平移后面的区间。
- `at(pos)` 给出从外到内的结构栈，用来画焦点框和状态栏。
- 索引不写入文档，也不成为布局缓存键的一部分。

样式表有自己的 `generation`。这一代变化时，整份结构索引重建。不能靠段落 `rev` 发现「样式定义改了，段落字节没改」。

## 作用域

内层先处理按键，不认识再交给外层：

```text
命令模式 → 公式内部 → 表格单元格 → 列表 → 正文
```

例如在表格里，上一块先按行走，到了第一行才离开表格。

## 焦点框

画布根据 `at(pos)` 和布局里的路径范围，在当前结构外画一圈淡框。框是叠加层。滚动和缩放只改绘制，不改文档。
