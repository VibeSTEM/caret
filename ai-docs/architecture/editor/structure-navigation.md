# 结构导航

更新日期：2026-10-29。键位见[快捷键](../interface/keyboard-shortcuts.md)，命令入口见[命令](commands.md)。

## 结构语义与界面类别

结构类别、页面角色和节点语义的唯一权威定义见[文档模型](document-model.md#页面层级与内容块形态)。本文件只规定结构索引、导航和焦点几何如何消费这些定义，不重述页面/内容分类。结构索引保存具体领域语义；界面只消费稳定 ID 和 Rust 投影，不根据标题文字、QML 节点树或具体 kind 再推断一次。

当前文档模型实现的块结构是 Paragraph、由段落大纲属性识别的 Heading，以及 `BlockEnvironmentKind` 的 `Section`、`Custom`。`Section` 和 `Custom` 共享可嵌套的标题/子项容器；`Section` 另有编号语义。二者都投影为 `multiLine`，但不能在 Rust 索引或文档数据中抹掉具体 kind。Custom 的实例名可覆盖通用显示名，模板扩展复用容器模型，不要求新增 QML 类别分支。

行内 `EnvironmentNode`（如 Bold、Italic、Font）参与格式和位置映射，不是块级导航停靠点。`InlineMath` 是 Paragraph 的行内原子；公式内部位置用 `MathPos`，不额外插入 Paragraph 之上的结构层级。Equation、Align、Table、Figure 的结构映射在相应文档节点实现并接入索引后启用；不能把计划项描述成已经可导航。

当前 `StructureClass` 只有 `Paragraph`、`SingleLine`、`MultiLine`、`Table` 和 `Figure` 内容块类别；页面组合层不是该枚举的同级成员。未来页面组合角色是否进入导航索引，按文档模型的层级语义另行接入。

当前文档模型尚无列表项节点/编号引用；010 需要先实现其语义和索引，再按列表项结构导航。列表连续范围是派生索引，不复制正文节点。

## 边界规则

| 单元 | 边界与行为 |
| --- | --- |
| Paragraph | 一个段落是一个结构停靠范围；内部 Run、行内环境和软换行仍属于该段 |
| Heading | 由 Paragraph 的样式/outline level 识别；自身是结构节点。可推导到下一个同级或更高级标题之前的大纲范围，但该范围不是可删除容器 |
| 块环境 | 可嵌套的语义容器；可选 title 是独立 Paragraph，不属于 `children`；结构删除作用于明确的环境子树，保留内容须使用单独的提升操作 |
| 列表项 | 计划中的块语义；一项对应段落，连续同列表引用形成派生列表范围 |
| PageSection | 页面几何配置，不是内容结构 |

删除普通 Heading 只影响该标题段落，不隐式删除标题范围内后续块。删除块环境才按该环境的明确子树边界处理。焦点框、当前环境背景高亮和字符选区是不同的视图叠加；它们不写入文档格式、不打印，也不修改结构修订。当前环境背景高亮的视觉规则由[031](../../task/031-environment-highlight.md)定义。

## 索引与更新

`caret-structure` 只读 `Document`，不依赖编辑引擎。索引是结构派生数据，不写入文档、不作为布局缓存键。布局几何来自同一代 `DocumentLayoutSnapshot`，避免 Qt 自行估算结构边界。

- 节点按文档顺序排列，用稳定节点 ID 表示身份和父链；保存 kind、层级与段落序号范围，不复制正文。
- `at(pos)` 沿稳定 ID 查出光标所在的外到内结构栈，供状态栏与画布使用。
- Heading 的跨块大纲范围和列表连续范围是派生数据。标题插入、删除、级别变化或大纲语义样式代际变化时，更新受影响的标题范围；列表项插入、删除和编号引用变化时，更新相邻列表的合并、拆分与范围。
- 块环境子树范围来自文档树，不从 Heading 层级推断。未变化的块内结构可复用；纯字色、字体度量和主题来源变化不重建结构索引。索引变化与布局失效分别处理。
- 每页的块环境范围由该页实际布局片段聚合，包含稳定环境 ID 和页面局部 pt 几何。跨页环境由多个页内范围表示，不能用一个跨页矩形近似。
- 结构增量更新的结果必须与对相同文档完整重建索引一致；拆分/合并、移动和撤销都按稳定 ID 与事务位置映射维护结构归属。

## 键盘作用域

结构导航按文档内部的最深可编辑对象优先；公式、表格行为在对应节点接入后逐步加入：

```text
公式内部 → 表格单元格/行 → 列表项 → 段落与块环境 → 正文
```

命令输入、IME 预编辑、选区和 UI 弹层是键盘交互上下文，不是文档结构层级。事件先由最内层焦点所有者接收；进入 Rust 的结构/编辑意图再由 Session 仲裁，详见[键盘路由](../interface/keyboard-routing.md)。例如表格内“上一块/下一块”先按行移动，越过首/末行时再离开表格；没有表格节点前不启用这项行为。

## 实现文件边界

```text
crates/caret-structure/src/
├── index.rs                       # 唯一索引装配入口与结构查询
├── index/tests.rs                 # 索引外部可观察结果
├── atoms.rs                       # 结构原子声明与内部导出
└── atoms/
    ├── paragraph.rs               # Paragraph / Heading 语义
    ├── block_environment.rs        # 块环境容器语义
    └── list_item.rs                # 列表实现后新增

crates/caret-engine/src/editing/session/
├── structure.rs                    # 结构命令入口与事务边界
└── structure/                      # 多职责增长后再拆分导航、环境操作

crates/caret-app/src/document_view/  # 生成当前结构与同代布局几何的只读投影
native/viewmodels/document/         # 校验、保存和发布 Rust 快照
native/canvas/document_canvas/      # 绘制焦点框，不保存结构真相
qml/Canvas/                         # 画布组合与 Theme 绑定
```

索引按语义拆分 atoms，但保持单一装配入口；不要为每个 kind 建平行索引。Session 命令在有独立职责和足够体量时再拆子目录，不提前创建空模块。Qt/C++ 只映射快捷键、校验快照并绘制 Rust 提供的页内范围；QML 只组合画布和绑定 Theme token。

## 焦点框

焦点框围绕光标所在最内层可导航块环境。当前结构栈确定稳定环境 ID，Rust 从同代布局快照取该环境在各页的实际范围；Qt 仅绘制这些页面局部矩形。段落/标题、列表项等没有容器范围的结构，不伪造块环境矩形。焦点框颜色和边框宽度由 QML Theme 提供。

滚动和缩放只改变绘制坐标，不改文档、结构索引或布局缓存。光标离开容器时清空焦点框；布局、分页或字体度量变化时使用新快照中的范围。当前环境背景高亮由 031 另行负责，可与焦点框复用范围来源但使用独立视觉 token 和绘制语义。
