# 结构导航

更新日期：2026-10-29。键位见[快捷键](../interface/keyboard-shortcuts.md)。

## 什么算结构

| 单元 | 怎么认 | 边界 |
| --- | --- | --- |
| 段落 | 一个 `Para` | 整段 |
| 标题 | Paragraph 的样式/outline level 表示标题 | 标题段本身。导航可以推导到下一个同级或更高级标题之前的“标题范围”，但它不是可删除的容器 |
| 块级环境 | 可导航的 `EnvironmentNode(scope: block)` | 可嵌套的语义容器；独立的可选标题和子块共同构成可导航范围，但标题不属于 `children`；可选中并用结构命令删除子树或提升子项 |
| 行内环境 | `EnvironmentNode(scope: inline)`，如粗体/斜体 | 对文字范围应用可嵌套格式；格式环境链从段落逻辑文本偏移派生，但默认不创建块级结构导航停靠点 |
| 列表项 | 段落带编号引用 | 一项一段；同一编号的连续段是一个列表 |
| 行内公式 | `InlineMath` 数学树 | 段落内原子对象；内部用 `MathPos` |
| 显示公式 | 块级 `Equation` 或 `Align` | 单行公式块或多行对齐公式块；内部用 `MathPos`，外部作为整体导航 |
| 表格 | `Table` | 表、行、单元格、单元格里的块 |

字符级的颜色等直接格式不算结构。PageSection 页面设置也不是内容结构。光标所在的最内层环境获得临时背景高亮：块级环境高亮容器，行内环境高亮文字范围。它是视图叠加，不写入文档或打印；与字符高亮、段落底纹分开。

标题范围和块级 `EnvironmentNode` 必须区分：删除一个普通标题段落不隐式删除后续段落；只有显式块级环境节点才有“删除整组子内容”的语义。环境标题的自动编号是编号定义的派生显示，不是标题 Run 中的普通文字。

## 索引

`caret-structure` 只读 `Document`。

- 节点按文档序排列，记下种类、路径、级别和范围。
- 每个顶层块记下生成它时的 `structureRev`。块内节点只在该块的结构修订变化时重算，插入和删除时更新后续路径和位置；纯绘制属性变化不重算索引。
- 普通标题推导出的跨块大纲范围和连续列表范围是派生数据，不能只看范围起点块的 `structureRev`。标题的插入、删除或级别变化，要重新计算受影响的标题范围；列表项的插入、删除或编号引用变化，要更新相邻列表的合并、拆分和范围。EnvironmentNode 的子树边界来自文档树，不从标题级别推导；嵌套环境在 `at(pos)` 结构栈中按外到内返回。未改动块的块内节点仍可复用。这些索引更新不触发布局。
- `at(pos)` 给出从外到内的结构栈，用来画焦点框和状态栏。
- 索引不写入文档，也不成为布局缓存键的一部分。

影响标题/大纲语义的样式定义有独立代际；该代变化时重建相应结构索引，不能靠段落 `structureRev` 发现「大纲样式定义改了，段落字节没改」。字色、字体度量和主题来源元数据不改变结构索引。

例如同级标题 A、B、C 中，把 B 改成正文，A 的派生大纲范围必须从 B 前延伸到 C 前，即使 A 的 `structureRev` 没变；如果它们位于 EnvironmentNode 中，环境的显式子树归属不会因此改变。反向恢复标题、插入或删除标题时也要更新派生范围。增量结果必须与对同一文档完整重建索引一致。

## 作用域

内层先处理按键，不认识再交给外层：

```text
命令模式 → 公式内部 → 表格单元格 → 列表 → 正文
```

例如在表格里，上一块先按行走，到了第一行才离开表格。

## 焦点框

画布根据 `at(pos)` 和布局里的路径范围，在当前结构外画一圈淡框。框是叠加层。滚动和缩放只改绘制，不改文档。
