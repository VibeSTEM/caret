# 公式与表格

更新日期：2026-10-24。

## 公式是树

公式存在内联对象里：一个 U+FFFC，加上一棵数学树，并可以保留进入时的线性文本。屏幕上的公式由这棵树排出来。LaTeX 是进和出的一种写法，不是编辑时的存储。

这样选是为了在公式内部移动、进占位符、做 `\alpha` 这种替换。代价是有的 LaTeX 写进去再写出来会变样。往返是否有损，要有夹具之后才知道，不能先假设无损。

另一种做法是在段落文本里直接存 LaTeX。那样导入容易，但编辑变成改源码，不符合所写即所排。不采用。

## 进出

- `$` 插入行内公式并进入。`$$` 插入独占一行的公式并进入。`$` 后再按 Tab 得到字面 `$`。
- 方向键在公式旁边时进入公式。Esc 离开公式，插入点落到公式之后。
- 公式内部可以上下左右移动，也可以跳到下一个占位符。
- `_` 和 `^` 在公式内进入下标和上标。
- 正文命令模式不会在公式内部打开。公式有自己的 `\` 替换。

离开公式只移动插入点，不产生撤销步。改了树的命令才记账。

## 表格

表格是块。单元格里是普通的块序列，所以单元格里可以有多段，也可以再放公式。第一版不允许单元格合并。

- Tab 到下一格，最后一格再按 Tab 增加一行。Shift+Tab 到上一格。
- 单元格里按 Enter 是新起一段，不是在表外插入行。
- 方向上的结构键在单元格之间移动，到边缘再离开表格。
- 插入默认 2×2。增删行列是独立命令。

大表格只重排 `rev` 变了的单元格内容。整表重排的开销在 M4 用一份宽表测量，测量前不设毫秒门禁。
