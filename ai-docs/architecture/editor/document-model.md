# 文档模型

更新日期：2026-10-24。

## 树

```text
Document
├── styles: StyleSheet { generation }
└── body: Vec<Arc<Block>>
    ├── Para(Paragraph)
    └── Table(Table → rows → cells → body)
```

```text
Paragraph
├── text          # 内联对象占一个 U+FFFC
├── runs          # 每段字节长度 + 字符属性
├── props         # 样式、大纲级别、编号、缩进
├── objects       # 公式等内联对象，顺序与 U+FFFC 对应
└── rev           # 全局递增，不参与相等，作为布局缓存键
```

标题是段落属性：样式名或 `outline_level`（0 到 8）。列表是段落上的编号引用。强调是 run 上的字符属性，不算结构。公式是内联对象里的数学树，可以单独成段显示。表格是块，单元格里又是块，因此可以嵌套。

修改段落时复制这一块并增加 `rev`。没改的块继续共享原来的 `Arc`。

## 位置

`Path` 是 `Vec<u32>`。顶层是 `[块]`。进入单元格是 `[表, 行, 格, 块]`，再嵌套就再加三个下标。字典序就是文档顺序。

`Pos` 是故事、路径和 UTF-8 字节偏移。选区记住锚点和焦点。公式内部另有 `MathPos`：节点路径加节点内偏移。它不属于 `Path`，避免和表格下标混用。

## 上限

公式树深度 64。表格最多 32767 行、63 列、嵌套 24 层。超过就拒绝这次命令，文档保持原样。

## `.cdoc`

原生文件是 UTF-8 JSON。

```json
{
  "format": "caret",
  "version": 1,
  "media": [],
  "document": {}
}
```

- `format` 必须是 `caret`，否则拒绝。
- `version` 是正整数。只有不兼容变化才加一：删字段、改语义、增加旧程序无法跳过的枚举。新增可选字段不加版本。
- 版本更高：拒绝打开，提示更新程序，不猜测内容。
- 版本更低：在内存里逐级迁移，保存时写成当前版本。
- 同一版本里，新字段带默认值。旧程序可以打开新文件，保存时可能丢掉它不认识的可选字段。信封可以留下不认识的顶层字段；`document` 内部不偷偷收集。
- 媒体放在 `media` 数组里，用 id 引用，内容是 base64。单个媒体超过 32 MiB 就拒绝插入。更大的外链不在第一版里。

保存先写同目录临时文件，fsync，再替换原文件。中途失败时原来的文件还在。畸形 JSON 返回错误，不 panic。

每个发布过的版本留一份夹具：读、写、再读必须相等；更高版本必须报错。
