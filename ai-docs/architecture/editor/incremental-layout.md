# 增量排版

更新日期：2026-10-24。

## 缓存

布局器输入是文档、缓存和一份环境（版心宽度、页边、是否正在打字）。输出是 `DocLayout`：每页的块位置，以及从路径到页内范围的索引，供命中和焦点框使用。

缓存的键至少包括：

- 段落 `layoutRev`（文字内容或影响度量的属性变化时递增；绘制属性变化不递增）
- 段落稳定 ID（避免不同段落的局部修订号碰撞）
- 版心宽度
- 影响字体度量、行框或段落几何的样式代际；纯字色、底纹等绘制属性与主题来源元数据不进入布局键
- 会改变这一段断行的环境，例如它在表格单元格里时的单元格宽度

段落 `layoutRev` 没变且环境相同，就复用上次的段落布局。`contentRev` 或 `paintRev` 单独变化不足以使布局失效。分页可以重跑，但不得因此重排每一个没变的段落。

命令模式、补全框、焦点框和选区装饰都不在键里。它们变了不调用布局。

## 什么时候整份失效

只有版心、影响排版度量的全局样式变更或分页规则这种全局变化才清空缓存。局部度量变更只使受影响段落失效；纯绘制属性只刷新绘制，不重排文档。普通编辑不清全局缓存。

不要为了方便往键里加字段。每加一个字段，都要在任务里写明它让哪些编辑失效，并附上同一份长文档在修改前后的重排范围。做不到这一点，就不要加。

## 还没有的数字

目标是：一次普通按键只重排脏段落，命中测试使用上一份快照。具体毫秒数等 M4 有基准再写。在那之前，文档里不出现「已经达到多少毫秒」这种句子。
