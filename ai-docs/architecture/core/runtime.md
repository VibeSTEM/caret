# 运行时

更新日期：2026-10-25。这是目标结构，代码还没有。

## 权威与派生

| 数据 | 谁写 | 谁读 |
| --- | --- | --- |
| `Document` | 只有文档命令 | 布局、结构索引、保存 |
| 选区、公式内光标 | 导航和编辑命令 | 画布、状态栏 |
| 命令模式查询 | `cmdline.*`，不进文档 | 补全弹窗 |
| `DocLayout` | 布局器，按缓存键 | 画布、命中、焦点框 |
| `StructureIndex` | 结构索引，按段落 `rev` | 结构命令、状态栏 |
| 主题、语言、设置 | 对应服务 | QML 经 ViewModel |

派生数据可以整份丢掉再算。丢了 `Document` 就不能算回来。

## 会话

`Session` 放在 `caret-engine`。界面经 `caret-ffi` 进入，`caret-cli` 经 `caret-app` 进入，测试可以直接调用。修改都走 `Session::run`。

```text
Session
├── document
├── selection
├── math: Option<MathEdit>
├── cmdline: Option<CmdLine>
├── undo / redo
├── layout_cache + last_layout
└── structure
```

`Session::run(id, params) -> Result<Effect>` 是唯一的修改入口。`Effect` 只说明这次变了文档、选区、叠加层还是插入点。QML 不保存第二份正文。

命令分两类：

- **文档命令**成功时压一个撤销快照。快照共享没改过的块，所以成本主要在被改的那几段。
- **纯命令**（补全移动、取消命令模式）不改文档，不产生撤销步。

连续打字合并成一步「输入」。进入命令模式时先结束这个合并，避免把命令和前面的字合成一步。撤销栈有上限，规划为 100 步，满了丢最旧的。

关闭文档或切换文件会使这一份 `Session` 失效。迟到的回调带着旧的会话代际，必须丢掉。

## 一次按键

1. C++ 收到键或 IME 事件，先判断组字。组字中的文本不进入命令模式。
2. 若命令模式、公式或结构导航认这个键，就组成命令 id 和参数。
3. `run` 在 Rust 里执行。文档变了，就只布局 `rev` 变了的段落，并增量更新结构索引。
4. Rust 交出新的页面快照。C++ 画布在后续帧里用这份快照绘制和做命中。指针移动不回到 Rust。
5. QML 更新补全列表、状态栏和焦点。它不解析文档字节。

长任务（打开大文件、以后的导出）在 worker 里做，完成时回到 GUI 线程提交结果。失败保留用户还有效的文档。

## 保存

保存走 `.cdoc`，步骤见[文档模型](../editor/document-model.md)。写入使用同目录临时文件、fsync、rename。路径由应用服务解析后再交给引擎，引擎不调用 Qt。
