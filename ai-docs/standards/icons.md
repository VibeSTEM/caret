# 图标

更新日期：2026-10-24。适用于随 QML 组件移植的 `qml/icons/`。组件见 [QML](qml.md)。

## 移植哪些

只移植原子组件和通用对话框实际引用的图标，以及同名的加载机制。窗口和编辑动作包括关闭、下拉指示、最小化、最大化、撤销、重做、新建、打开、保存、搜索、设置、勾选、复制和删除。

网格、浇注、结果视图和任务树专用图标不入库。新增图标先确认没有相同概念，再加入 SVG 和引用它的组件。不引入第三方图标包或图标字体。

## 资源

- 一个概念一个文件：`qml/icons/<name>.svg`。经 `qt_add_resources` 打进 `Caret.Shell`。
- 保留 viewBox 和路径比例。显示尺寸用 Theme 的逻辑像素。资源里不嵌位图、字体、脚本或外部 URL。
- `ThemedIcon.preserveSourceColors` 是颜色模式的唯一开关。彩色 SVG 直接从 qrc 加载。单色 utility glyph 走 `image://caret-icons/<name>/<argb>`，由 QtSvg 着色。未知 ID 拒绝着色。
- 装饰性图标对屏幕阅读器隐藏。按钮用宿主文案提供可访问名称，并保留焦点和禁用原因。

测试核对：组件里的图标名都有文件，彩色和单色名单与加载路径一致。
