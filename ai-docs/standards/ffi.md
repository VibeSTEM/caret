# 跨语言边界

更新日期：2026-10-24。Rust 与 C++ 使用 [CXX](cxx.md)。Python 绑定未接入。

## 项目规则

- 桥接签名保持安全。两侧调用方不写 unsafe。`unsafe extern` 和生成胶水是审查点，不是待删除的死代码。
- 每个接口写明所有者、销毁方、有效期、线程和错误。字符串写明编码和长度。数组写明布局、对齐和数量。句柄写明失效后的行为。
- 不共享 `std::string`、Rust `String` 或 `QObject` 的内存布局。
- 分配方提供对应的释放入口，不跨分配器随意释放。释放后的句柄不能再被旧回调使用。
- 关闭文档或切换会话后拒绝旧修订的回调。大数据先用清楚的所有权，再考虑借用。
- 领域 crate 不依赖 `caret-ffi`。native 能力通过窄接口注入。

修改签名时，同一次变更更新本仓库的调用方、生成输入和验证。成功返回只是最小检查；还要覆盖错误转换、空输入和大输入拒绝。同步测试不能代替线程和关闭时序的证据。
