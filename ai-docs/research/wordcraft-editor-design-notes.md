# WordCraft 编辑器方案参考笔记

更新日期：2026-10-25。来源是用户提供的 `editor-design.md`，该文档将 WordCraft 源码静态阅读固定在 commit `254351c01bc6e498eaede5c1bd79050d3f2d5c23`。本文件只提炼可供 Caret 设计讨论的事实和候选方案，不把来源项目的代码、注释或功能状态当作 Caret 的实现证据。

## 可迁移的工程问题

- 文档的语义结构、文字格式、页面设置和屏幕排版结果需要分开。分页和 glyph runs 是派生数据，不能成为用户内容的第二份权威副本。
- 纸张和文字字号使用稳定物理单位；缩放、逻辑像素、设备像素比只参与显示和命中坐标换算。
- 页面设置需要有明确归属（文档或节），不能把屏幕页边留白当作打印边距。
- 文字塑形要处理脚本、方向、字体回退和 cluster 映射。排版与光标移动不可把字节、码点、字素簇和 glyph index 混为一个位置单位。
- 行距应是有类型的段落属性；自然行高来自字体度量和行内对象，不能简单等同字号。段前、段后和软换行也需单独定义。
- 字色、文本高亮、字符底纹、页面颜色和工作区颜色有不同语义；“自动”“无颜色”和白色也不能合并。
- 格式查询要能表示统一值、混合值和不可用；空选区的待输入格式要与既有内容格式区分。
- 缓存失效、撤销事务、IME 组合和失败原子性都要能用行为测试验证。

这些要点已拆入[文档模型](../architecture/editor/document-model.md)、[格式语义](../architecture/editor/text-formatting.md)、[文字塑形](../architecture/editor/text-shaping.md)和[页面与段落排版](../architecture/editor/page-layout.md)。建议值和 WordCraft 单一实现的细节仍是候选项，不能直接视作产品默认或 Word 兼容承诺。

## Paragraph/Run 与版权

“段落里含有带字符属性的连续文字范围”是常见的富文本建模方式。就版权而言，中国《计算机软件保护条例》第六条明确，软件著作权保护不延及开发软件所用的思想、处理过程、操作方法或数学概念；美国 17 U.S.C. §102(b) 也排除思想、流程、系统和操作方法。WIPO 对跨国一般原则的说明同样区分思想与表达。引用：[中国软件保护条例](https://www.cac.gov.cn/2013-02/08/c_126468744.htm)、[美国法典第 17 编 §102](https://www.copyright.gov/title17/92chap1.html)、[WIPO 版权保护说明](https://www.wipo.int/en/web/copyright/protection)。

因此，单独采用 Paragraph/Run 概念通常不会仅因结构相似就构成版权侵权；这不是针对具体司法辖区、事实和产品的法律意见，也不等于完成了专利检索。源代码、文档、图表、测试和具有独创性的具体表达可能受保护；许可证、专利、商业秘密和商标是不同问题。若借鉴开源实现，须先核对许可证和实际复用范围。Caret 的实现应按本仓库规格独立编写，不复制 WordCraft 代码或其文字、图表、测试数据。

官方来源只支持上述一般性判断，不替代对具体实现或商业发布的法律审查。设计结论和是否需要外部法律意见由 [020 文档模型决策任务](../task/020-document-model-decision.md)跟进。

## 当前设计结论

先把“Paragraph/Run 是不是侵权”与“它是否适合 Caret”分开：版权担忧本身不足以要求发明一套全新结构。用户已决定 Paragraph/Run 保存文字，粗体/斜体等行内格式和可嵌套块环境都可以用 EnvironmentNode 表示；页面设置独立放在 PageSection 中，自动分页归布局结果。具体环境 kind、格式继承、编号、删除和文件格式约束由 020 细化。

这个决定不是对 WordCraft 结构或实现的确认，也不是 DOCX 兼容承诺。段落/Run 是文本表示；EnvironmentNode 可以在段内表示粗体/斜体作用域，也可以作为块容器表达 Caret 自己的层级、背景、列表/章节内容、公式和表格组合。操作日志/协作序列目前没有 Caret 的需求支撑，不能只因未来“可能协作”就把它设为文件的权威表示。逐场景比较和剩余设计事项见 [020](../task/020-document-model-decision.md)。
