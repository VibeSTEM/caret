# 060 — 字号命令与局部字号格式

## 目标与背景

为选区和插入点提供可观察、可撤销的字号调整。字号属于度量属性，会影响 shaping、行框、分页、光标和选区几何；Rust 文档与编辑会话持有权威格式状态，Qt/QML 不维护第二份。

- [数值与单位](../standards/numeric-values.md)、[分层](../standards/layering.md)、[测试](../standards/testing.md)

## 范围与非目标

- 定义并实现局部字号直接属性、命令入口、单位解析/校验、选区格式查询和 pending typing；存储使用整数百分之一 pt。
- 非空选区统一设置字号；空选区设置下一段输入的字号，移动插入点后按当前位置重新解析。
- 定义主题/环境继承、显式局部值、mixed 查询与清除局部字号行为，遵循格式语义文档的属性优先级。
- 只使受影响文本的 shaping/layout 与相关分页失效；不实现颜色/底纹、段落间距命令、文档主题编辑 UI 或字体族选择。

## 前置条件与待决策

- 实施前核实 Run/Paragraph `props` 的类型校验与 `.cdoc requiredFeatures` 规则，明确字号允许的节点类型及能力标记。
- 先写可观察的参数输入状态：格式化选区、光标待输入、无效值、取消、IME 和键盘导航；复用命令状态机，不在 QML 新增权威状态。
- 若现有模型不能表达字号继承或清除，先更新格式语义/模型文档，再实现。

## 实施步骤

1. 审核局部格式值、布局入口和缓存失效链，确定唯一持久化字段。
2. 设计并实现命令参数与查询状态，覆盖统一选区、pending typing、清除和失败原子性。
3. 接入 Parley shaping 与 Rust 布局，验证跨段分页及字形度量更新。
4. 补模型、编辑、持久化、Qt/QML 可观察行为验证，并记录短文档/长文档耗时或分配基线。
5. 更新命令、模型和格式文档，完成独立评审与复验。

## 风险与回退

字号影响 shaping 和分页；失效范围过宽会造成卡顿，过窄会留下旧几何。以 Rust 有效样式结果为唯一来源，按 revision/generation 传播变化。
