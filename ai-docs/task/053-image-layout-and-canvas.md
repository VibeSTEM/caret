## 目标与背景

为 052 定义的行内图片提供与 Rust 文档布局一致的行高、分页、命中和画布绘制，确保导入导出的图片不是仅存储但不可见的内容。

## 范围与非目标

- 将图片尺寸和基线/行框关系纳入 Rust 排版，输出与文本一致的布局快照。
- 支持图片命中、选中、光标两侧定位、分页和缩放；保留可访问替代文本。
- Qt 消费 Rust 生成的几何和资源，不在 QML 重算布局。
- 不实现浮动图片、文字环绕、裁剪工具或图片滤镜；这些需要独立布局设计。

## 前置条件与待决策

024、027、052 完成。固定超出页面宽度的缩放/裁切策略、图片与基线对齐规则、DPR 缩放与栅格缓存上限。

## 实施步骤

1. 定义图片对象度量与文本行框/分页的交互。
2. 将图片区域、替代文本和命中范围加入布局快照。
3. 在 Qt scene graph 绘制图片并验证纹理/资源生命周期。
4. 测试窄页、超大图、多页、缩放、缺失资源及增量重排；独立评审后更新记录。

## 预计改动

`caret-layout` / `caret-engine` 图片布局与快照、`native/` 场景图纹理消费；不把 Rust 排版规则重复放进 QML。

## 验收标准

- [ ] 图片尺寸影响行框、分页、光标和命中几何，结果由 Rust 提供。
- [ ] Qt 能稳定绘制并释放资源；文档缩放与 DPR 变化后图像清晰、几何一致。
- [ ] 缺失/损坏图片显示明确占位并保留替代文本。
- [ ] 插入或修改图片只使受影响段落/页面失效，未改页面可复用。
- [ ] 黑盒几何与画布测试及图像资源性能验证通过；独立评审完成。

## 风险与回退

高分辨率图可能引发解码峰值和纹理内存压力。按 052 的资源限制解码，纹理采用有界缓存；超限显示替代文本和诊断。
