# 035 — 文档工作模式语义与行为

- 状态：planned
- 依赖：018
- 优先级：P2
- 创建 / 更新：2026-10-28 / 2026-10-28

## 目标与背景

018 提供 Editing、Review、View 三种模式的标题栏选择 UI。本任务定义并实现模式的真实语义，避免界面选择与文档命令权限脱节。

## 必读

- [界面外壳](../architecture/interface/ui-shell.md)、[命令](../architecture/editor/commands.md)、[运行时](../architecture/core/runtime.md)
- [分层](../standards/layering.md)、[文档模型](../architecture/editor/document-model.md)、[测试](../standards/testing.md)

## 范围与非目标

- 明确 Editing、Review、View 三种模式各自允许的命令、保存行为、复制/查找能力和 UI 状态反馈。
- 明确 Review 对插入、删除、格式变更和批注的表达与接受/拒绝规则；检查是否需要文档模型及 `.cdoc` 能力扩展。
- 明确模式由 Rust 管理的状态边界：会话或文档级别、切换文档后的行为、保存后重开是否恢复，以及模式状态是否写入 `.cdoc`。
- Rust 是命令权限判定的权威；QML 负责显示模式和禁用不可用操作，不能仅靠隐藏控件实现只读保护。
- 不在本任务重做 018 已完成的标题栏视觉样式，也不实现协作、云端审阅或权限账号系统。

## 前置条件与待决策

- 018 的模式菜单 UI 已实现并完成独立评审。
- 开始实现前先定稿 Review 的修订与批注数据模型、保存格式兼容方式，以及模式状态是否持久化；未知文档能力应遵守 021 的兼容策略。

## 实施步骤

1. 对照三种模式的产品定义，写出命令允许矩阵和模式切换状态规则。
2. 设计 Review 修订与批注的文档表示、撤销语义、保存兼容策略和迁移边界。
3. 在 Rust 会话/应用服务实现模式状态与命令授权；通过 FFI 暴露只读状态供 QML 投影。
4. 连接选择器、快捷键和操作控件；未授权操作由 Rust 返回稳定错误码，界面显示一致反馈。
5. 覆盖模式切换、编辑命令拒绝、审阅修订往返、保存重开和撤销边界；独立评审并更新架构文档。

## 预计改动

可能涉及 `caret-engine`、`caret-app`、`caret-doc`、FFI、ViewModel、QML 命令控件、`.cdoc` 能力声明和相关架构文档。Review 的数据模型尚未决定，结构变更须先完成设计记录。

## 验收标准

- [ ] 三种模式的命令允许矩阵和切换规则已明确并写入架构文档。
- [ ] Rust 权威执行权限约束，直接调用 FFI 也不能绕过 View 模式只读限制。
- [ ] Review 修订和批注按确认的文档模型保存、重开、接受/拒绝和撤销。
- [ ] 模式切换遇到 IME、未提交操作或异步保存时行为确定，不丢内容、不误报保存状态。
- [ ] 新旧 `.cdoc` 的读写兼容、requiredFeatures 和未知能力安全预览符合 021 约定。
- [ ] 自动化测试、真实 UI 验证及独立评审通过；限制和兼容边界已记录。
