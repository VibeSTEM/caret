# 011 — M3：数学公式

- 状态：planned
- 依赖：010、042、043、044、045、046
- 优先级：P2
- 创建 / 更新：2026-10-25 / 2026-11-01

## 目标

完成行内公式、单行显示公式和多行对齐公式的端到端编辑体验，并验收它们在正文与表格单元格中的模型、编辑、布局、绘制和导航。

长期模型、LaTeX 子集、文本岛、字体与编辑行为以[数学公式架构](../architecture/editor/math.md)为准。本文只维护 M3 的交付拆分、总体验收和验证证据。表格模型与公式交叉边界见[公式与表格索引](../architecture/editor/math-and-table.md)。

## 范围与非目标

正文公式由 042–044 交付；单元格公式由 045/046 接入。首版只验收无编号公式；不包含公式图片导出、多字体切换 UI 或表格自身功能以外的扩展。失败保留、焦点迁移和兼容策略遵循数学公式架构，不在本 task 复制。
