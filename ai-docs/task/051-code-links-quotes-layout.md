## 范围与非目标

- 代码块的字体、换行、缩进、背景与分页行为；呈现代码时不得执行源内容。
- 行内代码的 shaping、光标、选区和命中几何。
- 嵌套引用块的边界、缩进/标记视觉和分页连续性。
- 多层嵌套及多段列表项的布局、缩进、编号和分页连续性。
- 链接的可见样式、选择命中和安全的用户触发导航边界；不自动打开外部 URI。
- 本任务不改变 050 定义的节点语义，不实现导入导出 parser/writer。
