# 036 — Icons8 图标替换与 Settings 关于页面署名

- 状态：planned
- 依赖：018
- 优先级：P1

## 目标与背景

为桌面应用统一替换当前图标，并按免费 Icons8 图标的署名要求提供可见、可点击的来源链接。当前 shell 中的图标先保持现状；用户计划在本任务实施时一次性手动选定并替换图标。

应用需要在 Settings 窗口中提供“关于”页面和对应入口按钮，并在页面中设置致谢/图标来源区域；不另建独立顶层关于窗口。若最终使用需要署名的免费 Icons8 图标，区域应显示可点击的 Icons8 链接。按用户提供的要求，桌面应用在关于页面提供一个链接即可覆盖所用图标，不需要逐个图标重复署名。

## 范围与非目标

- 用户提供并确认最终图标集合；以选定的 Icons8 图标替换当前对应资源，保持资源命名、QML 引用和 Qt 图标注册一致。
- 在现有 Settings 窗口中新增可访问的“关于”页面入口按钮和页面，展示应用名称、版本及致谢信息。
- 使用需署名的免费图标时，在关于页面的致谢区域显示明确、可点击的 Icons8 链接；链接对比度、键盘焦点、读屏名称及外部打开行为符合现有主题和可访问性约定。
- 如果最终选用的图标许可不要求署名，仍可保留通用致谢，但不显示误导性的许可声明。
- 不重做工具栏布局，不引入付费资产，不在本任务改动图标之外的产品插画或文档内容。

## 前置条件与待决策

- 用户提供最终图标文件，或确认可由实现者按已确认的 Icons8 页面选择并获取图标。
- 核验每个实际使用图标的许可条件；本任务依据用户提供的免费图标署名要求，在桌面致谢区域提供一个 Icons8 链接。
- 确认应用版本字符串来源；关于入口固定放在 Settings 窗口的页面导航中，优先使用构建版本元数据，避免重复维护版本号。

## 实施步骤

1. 盘点当前实际引用的图标及目标替换清单，核验 Icons8 资产的许可与署名要求。
2. 接入替换后的 SVG 资源，沿用统一图标注册路径，不在 QML 使用处硬编码另一套图形。
3. 在 Settings 窗口增加“关于”页面和导航按钮；在致谢区域展示可点击的 Icons8 来源链接，并处理外部链接打开失败。
4. 补充英文及中文文案、组件测试、格式和 lint 检查。
5. 按验证与评审规范进行独立评审，处理发现后复验。

## 风险与回退

图标许可条件可能因资产类型或下载方式不同而异。以最终实际使用资产对应的 Icons8 许可说明为准；若授权条件不满足，替换为许可兼容的资产，或保留原图标，不移除署名要求。
