# 023 — 页面尺寸、节与几何

## 目标与背景

为排版提供稳定物理页面几何。页面属性属于文档；滚动区、阴影和缩放属于视图。

## 必读

- [文档模型](../architecture/editor/document-model.md)、[页面与段落排版](../architecture/editor/page-layout.md)、[运行时](../architecture/core/runtime.md)
- [分层](../standards/layering.md)、[Rust](../standards/rust.md)、[测试](../standards/testing.md)

## 范围与非目标

实现 020 选定模型中的节/页面属性，支持 A4/A3、方向、四边边距和有限值校验。内部用 pt 并保留精度。MVP 可以只提供一个节，但自动分页不能存成页面对象。

不包含页眉页脚 UI、复杂分节范围、DOCX 导入导出和 Web 重排模式。

## 前置条件与待决策

020 定义 `PageSection` 的字段与范围契约；021 按该契约实现持久化。这里的 PageSection 只保存页面几何，不是内容层级的 EnvironmentNode。Normal 预设、默认纸型、数值边界和 mm 显示以设计决策为准。

## 实施步骤

1. 固定单位换算、有效范围和边界误差。
2. 实现页面属性命令与撤销接口。
3. 验证横纵向转换和无效边距原子拒绝。
4. 独立评审并复验。

## 预计改动

caret-doc 的 PageSection 属性、caret-engine 页面设置命令、布局输入和测试。

## 验收标准

- [ ] 横向改变几何参数，不旋转画布图像。
- [ ] 非有限值、非法边距被拒绝且文档/历史不变。
- [ ] pt 与 UI 单位换算误差有上界。
- [ ] Zoom/DPR 不修改文档页尺寸或换行输入。
- [ ] 独立评审和测试通过。
