## 目标与背景

用户插入表格，在单元格间移动，并增删行列。单元格里是普通段落。这是需求 M3 的表格部分，和 011 并行，不互相等待。

## 必读

- [公式与表格](../architecture/editor/math-and-table.md)、[结构导航](../architecture/editor/structure-navigation.md)
- [快捷键](../architecture/interface/keyboard-shortcuts.md)、[命令](../architecture/editor/commands.md)

## 范围与非目标

实现 `insert.table`、`table.insertRow`、`table.deleteRow`、`table.insertCol`、`table.deleteCol`。默认 2×2。Tab 到下一格，最后一格再按 Tab 增加一行。单元格里 Enter 新起一段。

第一版不允许单元格合并。不实现表格专用的 `\table` 以外的复杂语法。

若 011 已完成，单元格可以再放公式；011 未完成时，单元格先只接受段落，不阻塞本任务。

## 前置条件与待决策

010 已 done。无合并单元格的需求。

## 实施步骤

1. 在文档模型里加入表格块和行、列、嵌套上限。
2. 实现插入和增删。结构键在单元格之间移动，到边缘再离开表格。
3. 保存后再打开，行列和单元格文字一致。
4. 画布画出网格。大表只要求正确，不在本任务承诺单元格级增量，那是 013。
5. 独立评审后复验。
