## 目标与背景

交付可插入、编辑、排版并保存的表格。012 是 M3 表格总体验收，具体实现拆成表格模型/交互和表格布局/画布两个边界。单元格使用 Caret 块序列，因此表格模型不依赖 `latex-rust`；公式在单元格内的数学布局由 044 接入。

## 必读

- [公式与表格](../architecture/editor/math-and-table.md)、[文档模型](../architecture/editor/document-model.md)、[结构导航](../architecture/editor/structure-navigation.md)
- [测试规范](../standards/testing.md)、[验证与评审](../standards/validation-and-review.md)

## 范围与非目标

完成 [045 表格模型与交互](045-table-model-and-editing.md) 和 [046 表格布局与画布](046-table-layout-and-canvas.md)，并核对保存往返、导航、显示与错误处理。首版默认 2×2，不支持合并单元格。

本任务不实现单元格公式的 MathBox 布局、字形绘制或命中；这些由 044 按[集成规则](../architecture/editor/math-and-table.md#m3-集成验收)完成。基础表格模块不得直接依赖 `latex-rust`。
