## 目标与背景

交付可插入、编辑、排版并保存的表格。012 是 M3 表格总体验收，具体实现拆成表格模型/交互和表格布局/画布两个边界。单元格使用 Caret 块序列，因此表格模型不直接依赖公式后端；单元格公式模型编辑由 045 接入，布局画布由 046 接入；两者复用 043/044 的数学能力。

## 范围与非目标

验收 [045 表格模型与交互](045-table-model-and-editing.md)、[046 表格布局与画布](046-table-layout-and-canvas.md) 和 [106 共享宿主交互](106-table-shared-host-interaction.md)，核对保存往返、导航、显示和错误处理。首版默认 2×2，跨格拖选用整表结构范围。合并单元格和矩形格选区留待后续设计。

表格模型与基础网格复用现有文档块和数学投影。结构删除由 106 接入共享事务。本任务补齐整表以及格内跨段和完整显示公式的富剪贴板范围，复用 [091 的 Blocks 片段](091-rich-clipboard-integration.md)及宿主位置、节点重映射和 Undo/Redo。格内嵌套表、格内显式分页符和超高行的行内分页依照 046 移交后续实现。

## 风险与回退

若表格节点把单元格内容限制为纯文本或单个段落，会阻碍多段内容与后续公式。持久化结构应基于块序列；公式模型/编辑由 045 实现，数学布局由 044 提供，单元格组合由 046 实现；不能将第三方数学类型塞进表格模型。
