## 目标与背景

按 020 决议实现 Rust 文档树和版本化 JSON 文件。持久化语义文档，不保存屏幕页、glyph runs 或光标图像。

## 必读

- [文档模型](../architecture/editor/document-model.md)、[运行时](../architecture/core/runtime.md)
- [分层](../standards/layering.md)、[Rust](../standards/rust.md)、[测试](../standards/testing.md)

## 范围与非目标

实现 020 选定的文档树与 DTO，涵盖空文档、Paragraph/Run、行内与块级 EnvironmentNode、PageSection 和其他结构对象。模型和序列化规则以[文档模型](../architecture/editor/document-model.md)为准。读写路径通过 caret-app/caret-engine，并遵循其中定义的 `.cdoc` 与原子保存契约。

不做文本输入 UI、排版、DOCX/PDF 导入导出或远程协作。

未知可选字段经局部编辑、拆分/合并和移动后的归属由 022 编辑事务实现与测试；021 只负责结构化保留和存储往返。

## 验收标准

- [x] 空文档和当前节点往返相等；较高版本拒绝。当前 v1 是首个格式版本，没有可迁移的旧版；将来定义旧版时随迁移器加入固定样例。
- [x] Unicode 文本往返逐码点保真；读写不得隐式做 NFC/NFD 规范化。
- [x] 未知可选字段往返保留；未知 `requiredFeatures` 的文档进入标注清晰的只读安全预览，未知数据不透明保留，不能通过序列化或文件存储绕过只读限制。
- [x] 主题快照有独立格式版本；当前没有可迁移的旧主题版本。旧/新版本不匹配时进入只读安全预览，不猜测解释；将来增加迁移器时必须在副本上验证成功再替换。
- [x] `ReadOnlyPreview` 保留可定位的未知节点原位、不透明数据和不支持能力原因；无法解析或无法定位节点边界时拒绝打开。占位绘制、提示横幅及复制/导出限制由 027/008 的界面集成验收。
- [x] 写入失败保留旧文件和内存模型。
- [x] 非法值拒绝且不部分修改文档。
- [x] 不序列化页面布局、选区或临时 IME composition。
- [x] 格式、lint、定向测试和两轮独立评审通过。
