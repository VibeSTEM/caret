## 目标与背景

基础设施已经能打开空白窗口。需求 M0 要在窗口里看见一页。本任务只做这件事需要的界面：标题、页面区域、一行状态。先写一张静态 HTML，再落成 QML。还不能打字或保存。

## 必读

- [需求](../architecture/requirements.md)、[界面外壳](../architecture/interface/ui-shell.md)
- [QML](../standards/qml.md)

## 范围与非目标

`design/html/` 里一份主窗口。然后用已有的 `Caret.Shell` 把同样的三块装进 `App.qml`，替换 005 的空白页。页面区域是占位，标出一页的范围。状态栏是一行文字。

不包含：补全层、设置、语言、新建文档、功能区、真实分页和输入。这些对话框即使已在组件库里，本窗口也不打开。

## 前置条件与待决策

006 已 done。无未决的 M0 画面范围。

## 实施步骤

1. 写静态 HTML：标题栏、页面占位、一行状态。桌面宽度和一档较窄宽度都能看全。
2. 按这张 HTML 改 QML。假标题可以用固定字符串，并标明还没接文档。
3. 启动窗口，与 HTML 对照。
4. 独立评审后复验。通过后 008 才开始。

## 预计改动

新建 `design/html/` 的主窗口页。改 `qml/App.qml` 和必要的占位。不新建编辑器 crate。

## 验收标准

- [ ] 窗口只有标题、页面区域和一行状态，没有功能区和对话框。
- [ ] QML 与 HTML 的这三块一致。窄宽度下三块仍完整。
- [ ] 占位不经过文档或 FFI 的文档类型。
- [ ] qmllint 和启动通过。评审发现已处理。
