## 目标与背景

基础设施已经能打开空白窗口。需求 M0 要在窗口里看见一页。窗口按简化后的文档外壳来：自定义标题栏、只留 Home 的工具栏、居中的页面、底栏。先写一张静态 HTML，再落成 QML。还不能打字；保存入口只选择文件路径，文档持久化留待 008。

## 必读

- [需求](../architecture/requirements.md)、[界面外壳](../architecture/interface/ui-shell.md)
- [QML](../standards/qml.md)

## 范围与非目标

`design/html/` 里一份主窗口。然后用已有的 `Caret.Shell` 把同样的结构装进 `App.qml`，替换 005 的空白页。

窗口包含：

- 自定义标题栏，画在系统标题区域里，保留平台窗口按钮。内容是文档名、搜索和设置齿轮；左侧快速操作含 AutoSave、保存、撤销和重做。AutoSave 目前只是关闭状态的视觉开关，策略单独由 019 设计。新文档显示 `Untitled`；临时文档点击保存打开系统保存对话框，默认路径为 `Documents/caret/Untitled.cdoc`。对话框选择路径只暂存目标，实际写入和更新标题留待 008。不放 Discord，不放账户头像。
- 工具栏只留 Home。右侧是 Comments、Editing、Share。
- 一页占位，在编辑区里居中。不画尺寸尺。
- 底栏左侧是页码、字数和语言，右侧只留缩放尺；缩放加减按钮使用主题着色的 SVG。

设置齿轮打开已经移植的设置对话框。页面、字数、语言和缩放不读文档。Comments、Editing、Share 和搜索没有命令。

不包含：补全层、语言页、新建文档、完整功能区、真实分页、输入和文档持久化。

## 前置条件与待决策

005 已 done，窗口能打开。006 仍是 CI，不挡这扇静态外壳。画面范围按 2026-10-25 的简化文档窗口。

## 实施步骤

1. 写静态 HTML：自定义标题栏、Home 与右侧三个按钮、居中的页面、底栏。桌面宽度和一档较窄宽度都能看全。
2. 按这张 HTML 改 QML。文档名、页码、字数和语言用固定字符串，并标明还没接文档。
3. 桌面入口在加载 QML 前注入 `caret-app` 已校验的内置主题快照。不在 C++ 再写一份 token 默认值。
4. 启动窗口，与 HTML 对照。设置齿轮能打开设置对话框。
5. 已有主窗口作为当前 GUI 基线。剩余窄宽度、设置齿轮点击和 HTML 并排核对属于未完成的外观验收；用户已决定暂停 QML UI，这些项目不阻塞 020、021、022 或 008。

## 预计改动

## 风险与回退

HTML 若做成可编辑页面，会抢 008 的行为定义。发现脚本在改内容，就删掉脚本。回退是恢复 005 的空白页并移除 HTML。
