## 目标与背景

用户用 `\` 改标题、列表和换页，并在插入点旁看见候选。这是需求的 M1，含输入法约束。补全层是这一步新增的界面，先写一小段静态 HTML，再落成 QML。

## 必读

- [命令输入](../architecture/editor/command-input.md)、[命令](../architecture/editor/commands.md)
- [快捷键](../architecture/interface/keyboard-shortcuts.md)、[界面外壳](../architecture/interface/ui-shell.md)

## 范围与非目标

实现 `cmdline.begin`、`cmdline.type`、`cmdline.accept`、`cmdline.cancel`，以及别名表里的标题、段落、列表、分页和换行。`\frac`、`\sqrt`、公式和表格别名留到 011、012，本任务可以让它们显示为尚未可用。

组字期间不进入命令模式。空格无效。Esc 取消并清掉查询。查询不改变文档 `rev`。

补全层只表达查询、高亮项和空结果，锚在插入点旁。不新做对话框，也不改 007 的窗口骨架。

不包含：结构跳转、公式树、表格、中文标点开关的默认开启。开关可以有设置项，默认关。

## 前置条件与待决策

008 已 done，文档能保存。无未决的命令键位。

## 实施步骤

1. 用一段静态 HTML 定补全层的位置和两种状态，然后按它落成 QML。
2. 在会话里实现命令模式和别名匹配。匹配顺序按命令输入文档。补全层绑定真实候选。画布在命令模式认领按键，QML 只反映高亮项。
3. 用真实输入法做一次组字检查。组字中的 `\` 不进入命令模式。
4. 标题、列表、分页各做一次可保存的往返。
5. 独立评审后复验。

## 预计改动

`design/html/` 里的补全片段、补全 QML、`caret-engine`、`caret-app` 的设置键、画布按键分派。不改 007 的窗口骨架，除非补全层被它挡住。

## 验收标准

- [ ] 补全层与 HTML 片段一致：锚在插入点旁，能显示候选和空结果。
- [ ] `\section` 把当前段变成一级标题，整条命令是一个撤销步。
- [ ] Enter 执行，空查询时 Tab 插入字面 `\`，空格不执行也不插入。
- [ ] Esc 取消且没有撤销步。组字期间不进入命令模式。
- [ ] 命令模式的查询不触发排版。测试、fmt、clippy 通过。评审发现已处理。

## 风险与回退

输入法事件顺序在 Qt 上可能和文档假设不同。验证失败就保持中文标点开关关闭，并把现象记入本任务，不改默认值。回退是隐藏补全层并忽略 `\`。
