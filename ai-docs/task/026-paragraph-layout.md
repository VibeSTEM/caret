# 026 — 行距、段间距与分页

- 状态：planned
- 依赖：023、024、025
- 优先级：P2
- 创建 / 更新：2026-10-25 / 2026-10-25

## 目标与背景

按字体度量、段落属性和页面几何生成行框与分页；固定行距、软换行、空段和对象不能按字号近似。

## 必读

- [页面与段落排版](../architecture/editor/page-layout.md)、[文字塑形](../architecture/editor/text-shaping.md)、[增量排版](../architecture/editor/incremental-layout.md)
- [文档模型](../architecture/editor/document-model.md)、[测试](../standards/testing.md)

## 范围与非目标

实现自然行高、Multiple/AtLeast/Exactly 三种 typed 语义，段前/段后、段落标记度量、内联对象、基本分页与显式分页。明确相邻段、新页首段和 Exactly 溢出策略。

不包含复杂表格分页、完整 widow/orphan 规则、文档网格和 DOCX 兼容模式。

## 前置条件与待决策

023 页面几何、024 shaping metrics、025 段落格式可用；默认值及固定行距溢出规则已决策。

## 实施步骤

1. 分离 line box、baseline、glyph ink bounds 和对象度量。
2. 实现行高类型及段间距规则。
3. 实现分页和跨页段落范围引用。
4. 覆盖对象、空段、tab-only、固定溢出和段间距边界。
5. 独立评审并复验。

## 预计改动

caret-layout 行/段布局、页结果、缓存失效和测试。

## 验收标准

- [ ] 三种行距的数值、对象下限和固定溢出语义有测试。
- [ ] 空段、空格、tab、图片/公式行不会零高或无限分页。
- [ ] 软换行不触发段间距；相邻段规则明确。
- [ ] 跨页片段引用同一文档范围，不复制正文。
- [ ] 结果正确性不依赖增量缓存；改动前后分页内容连续、无丢失或重复。
- [ ] 独立评审和测试通过。

页边界错误会漏字或重复。先保证跨页内容区间连续且不重叠，再优化重排范围。
