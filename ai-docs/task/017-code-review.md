## 目标与背景

按用户要求整体审查当前已实现的代码，在保留产品范围和分层约定的前提下修复有证据的问题。GoogleTest 独立生产另在 016 分支推进，006 在其发布后跟进消费；本任务覆盖应用服务、DSL、工具供给、FFI/native 和质量调度。

## 范围与非目标

审查当前可达生产代码及测试，重点核对失败保留有效状态、生命周期、输入边界、路径、解析和资源供给。只修复经核实的问题，性能优化需要可解释的输入规模或行为收益。不增加正文编辑能力，不进行无关依赖升级。

## 前置条件与待决策

编号 016 已保留给独立 `yuki/googletest-package` 分支。审查不依赖其远程完成；006 的正式 SDK 消费等待三平台资产及摘要。

## 实施步骤

1. 按模块只读独立审查，汇总文件、触发条件和影响。
2. 主代理确认发现，补最小回归并修复。
3. 跑受影响检查；跨边界变更再执行完整质量聚合。
4. 独立复核修复，记录结果和限制。

## 预计改动

由实际发现决定，限定现有模块；更新本任务和索引。不提前列虚构问题。

## 风险与回退

整体审查可能超出 006。修复按实际模块和本任务记录，不把缺少实现的产品功能作为现有缺陷。若优化改变输入契约，先核对架构和规范，再决定是否属于本任务。

## 决策与工作记录

- 2026-10-25：用户要求在独立 SDK 打包后整体 review 并优化代码；先并行进行不依赖 SDK 发布的只读审查。
- 2026-10-25：路径祖先探测改为 `symlink_metadata`，悬空链接也必须规范化并通过包含检查，不能绕到根外尚不存在的目标。设置临时文件和隔离文件名改用 `OsStr` / `OsString`，不强制 UTF-8。
- 2026-10-25：DSL 统一支持双引号转义，保留引用标量尾部空白，拒绝空 `src` 后重复声明，`kind : fsm` 与 grammar 分流一致。诊断位置索引每次 parse/evaluate 建立一次，按行起点和非 ASCII 额外字节索引计算字符列，避免重复扫描。
- 2026-10-25：同机 Apple M4（Mac16,12）、macOS 27.0.1 arm64、Rust 1.99 debug CLI `check`，stderr 重定向到空设备。4k/8k/16k 非法转义的修复前单次耗时约 0.178/0.724/2.518s，修复后五次中位数为 0.0269/0.0482/0.0923s；1,048,060 字节、约 524k 转义的完整诊断约 3.066s。前后采样方式不同，只用于展示该病理输入的复杂度改善，不作为通用吞吐或 CI 毫秒门槛。
- 2026-10-25：工具缓存有效性检查和自愈重装统一放在安装锁内，四线程回归只修复一次。普通相对 `CARET_TOOLCHAIN_ROOT` 锚定仓库根，Windows `D:tools`、`\tools` 等歧义形式拒绝；launcher 显式传入已解析根，避免 Rust/CMake 各自按 cwd 解释。
- 2026-10-25：按用户要求整体优化注释，把“新建工程窗口”等来源领域表述改为文档窗口、文档会话和资源根；涉及原生文件时使用 `.cdoc`。清除不存在的任务编号、来源运行号和未经验证的数字，保留真实来源、`project:/`、标准库 STL 以及构建术语。
