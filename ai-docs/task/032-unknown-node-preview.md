# 032 — 未知节点安全预览

## 目标与背景

读取器遇到未知节点或必需能力时，不能把未知语义静默丢弃，也不能假设已知部分的排版代表全文正确。提供受限的只读安全预览，保留未知数据并清楚提示不支持能力。

## 必读

- [021 文档树与存储](021-document-tree-and-storage.md)、[027 画布与命中](027-canvas-and-hit-testing.md)
- [文档模型](../architecture/editor/document-model.md)、[分层](../standards/layering.md)、[测试](../standards/testing.md)

## 范围与非目标

解析已知文件外壳和节点边界；未知节点作为不透明数据保留，在原位置绘制占位和不支持能力提示。发现未知必需能力时以只读方式打开安全预览，禁用编辑和保存。已知内容尽力显示，但界面明确全文分页/样式可能不准确。

复制或导出若会遗漏不透明内容，必须禁用并说明原因；不实现未知节点语义、自动降级转换、云端转换或未来版本迁移。

## 前置条件与待决策

021 的不透明字段保留、`requiredFeatures` 判定与原子写入规则可用；027 已提供页面坐标和 Canvas/ViewModel 快照基础。未知节点的布局占位几何、提示与只读呈现由本任务补齐。开始时确认解析器能区分未知可选字段与未知必需能力。

## 实施步骤

1. 核验存储模型对未知节点/字段及原始字节的保留范围。
2. 定义只读预览状态和不支持能力清单，从 Rust 服务向界面提供只读 DTO。
3. 在布局中给未知节点保留位置并输出占位几何；不假定其正常排版语义。
4. 禁止会丢失未知内容的保存、复制和导出；覆盖错误与往返路径。
5. 完成独立评审并复验。

## 预计改动

`caret-doc` 文件模型/读取器、`caret-app` 文档打开状态、`caret-engine` 预览布局、FFI/ViewModel 和 Canvas 占位呈现。只修改实际需要的层。

## 验收标准

- [ ] 未知可选数据可无损保留；未知必需能力进入明确的只读预览状态。
- [ ] 未知节点在其逻辑位置显示占位与能力提示，不伪称完整正确排版。
- [ ] 只读预览不能执行编辑或保存；可能丢失不透明数据的整篇复制/导出不可用。
- [ ] 关闭、重开、错误文件和已知旧版本迁移路径有测试；失败时不破坏原文件。
- [ ] 真实窗口展示提示与占位，独立评审通过。

## 风险与回退

若现有 `.cdoc` 表示无法安全保留未知节点原始内容，则先补存储模型并让不兼容文件拒绝打开；不得先实现一个会丢数据的近似预览。回退路径是拒绝打开该文件并保留源文件。
