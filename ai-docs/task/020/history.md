# 020 评审与决策记录

本页是任务 020 的历史评审发现、边界示例和逐项决策记录。当前规则以[文档模型专题索引](../../architecture/editor/document-model.md)及其链接的权威规范为准。

## 独立评审发现与处理

2026-10-25 的只读评审确认 Paragraph/Run + 语义树无需推倒重来，但以下不变量需在 M0 实现前定稿：

1. **属性归属与关闭**：已按用户决定采用环境级 `enabled: true|false`；Run 不保存粗斜体覆盖，缺少该 kind 节点表示继承，false 遮蔽主题/祖先开启，内层 true 可重新开启。
2. **相交范围**：格式区间不能在树中交叉；操作在合法字素边界切分，新环境放在目标叶片段的最内层以保留既有祖先和模板优先级；只有单次操作一起创建的多个环境才使用稳定 kind 顺序 Bold → Italic → Font。不同命令顺序可生成不同树；Font=A 内含 Font=B、Bold=on 内含 Bold=off 都不是冗余。
3. **文本边界与光标**：分段基于 Paragraph 的逻辑文本，跨 Run/行内环境；逻辑环境亲和性只决定输入继承，视觉方向与 bidi caret 由布局单独映射。
4. **位置和编号**：用稳定终止节点 ID 锚定位置、从树索引重建路径；所有结构改写返回映射。计数域已明确按最近已编号祖先和显示层级共享；缺标题 Section 不显示且不计数，解除时不合成标题。
5. **兼容预览**：未知能力不代表已正确打开；明确占位、提示、保存和导出限制。未来主题结构仅迁移已知旧版本，失败不得替换原快照。
6. **成本与缓存**：结构共享不代表宽 Vec/长 Paragraph 编辑免费；Undo 后新分支必须使用不重复修订令牌，异步布局结果仍以文档 generation 防旧结果覆盖。

首轮评审列出的设计缺口已写入架构规范和实现验收。中间复审发现的模板优先级及 Section 后代重排问题也已修复；未知可选字段在节点变换时的保真要求已加入 021。Custom 编号透明、未编号祖先省略、关闭编号不占号、字素内位置非法、标题空后缀、文件打开失败保留有效文档及主题更新失败保留旧快照均保持原决定。最终独立评审通过，未发现未处理的 P1/P2，020 满足关闭条件。

### 定稿边界示例

#### Section 计数域

```text
Section 1
├── Section（编号关闭）A
│   └── Section（编号开启）X
└── Section（编号关闭）B
    └── Section（编号开启）Y
```

- X/Y 共用最近已编号祖先 `1` 的下一层计数域，显示 `1.1`、`1.2`，不按未编号直接父节点重启计数。
- 若树中没有已编号祖先，第一条启用编号的后代进入文档级计数流，从下一个可用顶层序号开始。
- `title: None` 的 Section 不显示标签、不占自身序号，作为结构容器对编号透明；空标题 Paragraph 则显示标签并占号。

Custom 同样对编号路径与计数流透明。关闭编号的 Section 仍有结构语义，但其编号后代跳过它，并按最近已编号祖先的显示层级接续计数。

#### 标题 Enter 的边界

- 光标位于标题开头/末尾时，按既定规则保留空标题前缀或创建空正文后缀段。
- 标题内选区 Enter 可按“删除选区后在其起点拆分”一次提交；跨标题与正文的选区若不能原子映射，则拒绝且保持原文、选区和 IME 状态不变。
- Return 尚用于 IME candidate 时先由输入法消费；composition 提交后再次 Return 才执行 Enter 命令。

这些规则用于实现前封口 020/022：标题内选区先被替换再拆分；跨标题/正文选区原子拒绝；IME composition 未提交时由输入法先处理 Return。
