# 025 — 字符与段落格式命令

- 状态：planned
- 依赖：009、021、022、024
- 优先级：P2
- 创建 / 更新：2026-10-25 / 2026-10-25

## 目标与背景

为选择范围和待输入文字提供语义格式操作，不把继承状态、颜色类型或段落属性压成含糊的简单值。

## 必读

- [格式语义](../architecture/editor/text-formatting.md)、[文档模型](../architecture/editor/document-model.md)、[命令](../architecture/editor/commands.md)
- [分层](../standards/layering.md)、[测试](../standards/testing.md)

## 范围与非目标

先支持文档默认字体设置和局部 Font EnvironmentNode 命令，再逐步支持字号、粗体/斜体、单线下划线、字色、高亮、字符底纹和基本段落格式。字体族不作为 Run 直接属性：文档默认拉丁族通过命令/API 修改，局部族由 `\font` 命令创建或应用 inline Font EnvironmentNode；字体名从 024 的本机字体目录获取。全局可设置 `defaultCjkFontFamily`，并按 ISO 15924 脚本标签配置细粒度覆盖；CJK 默认包含 `Hani`、`Hira`、`Kana`、`Hang` 和 `Bopo`。数学公式字体由 011 的 `defaultMathFontFamily` 独立设置，不属于正文字体选择器或正文脚本字体候选链；首版默认并仅支持 STIX Two Math。语言继续使用 BCP 47 标签，不能用字体族配置代替语言元数据。当前不做独立字体选择窗口或新工具栏控件。粗体/斜体范围由行内 EnvironmentNode 包裹，格式操作注册到命令系统，不增加环境工具按钮。实现文档全局格式设置、主题选择和默认 Run/Paragraph 样式；主题加载及显式更新走命令/API，主题快照更新失败必须保留旧快照和样式引用。块级 EnvironmentNode 的创建、嵌套、选择和删除由 010 通过命令与结构快捷键处理，本任务不重复实现。当前环境背景高亮不由格式命令设置，随光标位置派生。保留嵌套继承，并在移除格式环境时 unwrap 子内容。保留继承状态，格式查询表达 uniform/mixed/unavailable；空选区更新 pending typing style。一次确认对应一个事务。

不包含完整 Word 样式兼容、所有 underline 枚举、透明色或工具栏视觉细节。

## 前置条件与待决策

021 数据模型、022 选择/命令、024 shaping 契约稳定。颜色及主题引用语义以 020 之后的架构为准。

## 实施步骤

1. 定义属性的继承、显式关闭和清除行为。
2. 实现默认字体命令和 Font EnvironmentNode 命令，基于 024 字体目录提供命令补全，不增加字体选择窗口。
3. 实现其他范围格式命令、inline environment wrap/unwrap 和格式查询。
4. 覆盖混合选区、空选区、空段、嵌套粗斜体、unwrap 边界与属性合并。
5. 独立评审并复验。

## 预计改动

caret-doc 样式类型、caret-engine 格式命令、格式查询 DTO 和命令测试。

## 验收标准

- [ ] 字色/高亮/底纹/页面色/工作区色语义互不覆盖。
- [ ] 默认字体命令修改文档全局默认；局部字体命令创建/应用 Font EnvironmentNode；Run 不直接保存字体族；不新增字体选择窗口或工具栏控件。
- [ ] 文档默认字体设置支持默认拉丁字体、CJK 默认字体、按 Unicode Script 短标签覆盖字体、脚本内 BCP 47 语言覆盖；混合文字能在 shaping 边界选择对应字体，并在 glyph 缺失时使用系统回退。
- [ ] 不同字体族的 Font 环境局部嵌套覆盖；同族范围合并/压平并按 020 保留节点 ID。
- [ ] 混合格式选区按[格式语义](../architecture/editor/text-formatting.md#选区与待输入格式)统一应用；空选区切换 pending typing，移动光标后按上下文重算；交叉范围按 020 的保序树化规则切分；只有状态、`definitionId`、`props` 和语义上下文兼容的同类型相邻环境才合并。行为测试覆盖主题/外层粗斜体的局部显式关闭、不同模板嵌套时保留已有属性优先级、空段标记格式、拆分、合并和 Undo ID 恢复。优先级命令测试固定全局字号 14 pt、Section 默认模板 18 pt 且实例无覆盖时环境内结果为 18 pt；实例变体/props 覆盖和环境未设置该属性时的全局/主题回退也分别断言。不同有效树形按正文、计算格式和位置映射断言，不以树完全相同作为通过条件。
- [ ] 自动颜色与显式白色可区分；未知格式保留或报告降级。
- [ ] 失败不部分修改；一个格式操作交给 018 作为一个撤销单元。纯绘制属性不使排版缓存失效；度量属性只失效其影响范围。
- [ ] 外部主题变化不自动应用；显式更新成功后才替换快照并推进对应样式代际，失败保留原快照、引用和可见效果。
- [ ] 独立评审和受影响测试通过。

## 风险与回退

把 unset 转成 false 会破坏继承。使用明确值类型及迁移测试。
