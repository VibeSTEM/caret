## 目标与背景

让用户能通过结构命令和快捷键在文档块之间导航、创建和操作块环境，并能看见当前所在结构。Rust 文档树和编辑会话是领域行为的唯一来源；Qt/QML 负责按 Rust 提供的结构类别和布局范围绘制状态与焦点框。

本任务使用[文档模型：页面层级与内容块形态](../architecture/editor/document-model.md#页面层级与内容块形态)作为结构分类的唯一权威定义；[结构导航](../architecture/editor/structure-navigation.md)定义索引和几何投影。任务文档只记录实现范围与进度，不复制节点类别和语义。

当前文档模型中的 `Section` 与块级 `Custom` 是 `BlockEnvironmentKind` 的具体语义类型：二者共用可嵌套块容器；`Section` 额外承载独立标题和编号语义，`Custom` 是带可选实例显示名和主题定义引用的通用容器。Custom 的目标模型支持 Page、Block、Inline 三种可选 scope，嵌套顺序固定为 Page → Block → Inline；本任务当前仅实现 Block-scope 实例，其余 scope 和统一定义管理留待后续任务。两者归入通用 `MultiLine` 类别，但 Rust 保留具体领域 kind。新增环境应沿用可组合的容器与索引结构，不在 QML 为每个具体 kind 添加分支。`InlineMath` 是 Paragraph 内部的行内原子，不是独立块结构。

## 范围与非目标

包括结构索引、段落/标题/块环境/列表项导航、块环境创建与嵌套、结构子树删除和显式提升、逐级扩大选区（覆盖段落和标题）、焦点框、状态栏结构类别，以及分页布局范围映射。结构命令由 Rust Session 执行；快捷键和命令输入只传递稳定动作意图，不由 QML/C++ 修改文档树。

普通标题可派生出大纲范围，但该范围不是可删除容器；删除标题只影响标题段落，不隐式删除其后续正文。本任务提供可复用的稳定结构 ID 与同源布局几何。焦点框是视图叠加层；当前环境的背景高亮规则由 [031](031-environment-highlight.md) 实现，本任务不实现 031 的颜色或行内环境背景高亮。

公式、表格、图形节点的模型与编辑分别由 011、012 及后续子任务接入；010 只定义通用索引/类别接口和当前已存在结构的行为，不提前伪造尚不存在的节点。公式内部移动、单元格内移动和新选区模型不在本任务范围。

## 前置条件与待决策

009 命令输入与 020 文档模型已完成。当前模型已有 Paragraph、Heading 样式、Section 与 Custom 块环境。`\section` 和 `\environment` 命令可创建对应结构；更细标题命令由后续任务实现。列表项语义、结构删除/提升和扩大选区仍需实现。环境类型只通过 Rust 内置注册表扩展；界面使用通用结构类别，不以标题文本或具体环境名推断类别。

## 实施步骤

1. 用稳定节点 ID 为段落/标题、块环境和列表项构建结构索引；标题范围、列表连续范围等派生数据在受影响边界更新，并能与完整重建结果对照。索引不写入文档、不进入布局缓存键；纯绘制或字体度量变化不重建索引。
2. 接入 Section/Custom 创建以及列表、嵌套、选中、删除、提升命令；操作通过 Session 事务产生位置映射和可撤销历史。
3. 将结构移动、跳出、逐级扩大选区和相关快捷键接入现有键盘路由；扩大选区至少支持段落与标题，并在命令输入、IME 和选区等上下文下不抢占其他按键行为。
4. 让布局快照对可导航块结构提供稳定 ID、页内范围和通用类别；跨页结构的范围由各页片段组成，不能用一个错误的单页矩形代替。
5. 画布用该快照绘制当前结构焦点框；滚动/缩放只改变投影，不触发文档编辑或结构重建。
6. 覆盖结构导航、列表边界、嵌套环境操作、撤销、分页几何与键盘作用域；完成独立评审并处理发现。

## 文件结构设计

结构派生逻辑放在 `crates/caret-structure/`，该 crate 只依赖 `caret-doc` 及允许的基础类型，不依赖编辑引擎。保持“单一索引装配入口 + 按语义拆分的 atoms”：

```text
crates/caret-structure/src/
├── lib.rs                         # 公开稳定结构查询 API
├── index.rs                       # 从文档块树装配索引、查询结构栈和顺序
├── index/tests.rs                 # 索引的可观察结果测试
├── atoms.rs                       # 结构原子模块声明与内部导出
└── atoms/
    ├── paragraph.rs               # Paragraph 与标题语义
    ├── block_environment.rs        # 块环境容器语义
    └── list_item.rs                # 列表项语义（实现列表后新增）
```

索引条目保留具体领域 kind、稳定 ID、父链和范围；`StructureClass` 是供状态栏/画布消费的通用类别投影。不要为每个具体 kind 建一套平行索引，也不要把正文复制到索引。

```text
crates/caret-engine/src/editing/session/
├── structure.rs                    # 结构命令分发、事务边界
└── structure/                      # 结构命令达到独立职责/体量后拆分
    ├── navigation.rs               # 前进、后退、跳出
    ├── environment.rs              # 创建、嵌套、删除、提升
    └── tests.rs                    # 结构编辑行为测试

native/viewmodels/document/         # 仅传递 Rust 快照与结构命令
native/canvas/document_canvas/      # 焦点框绘制，不持有结构真相
qml/Canvas/                         # 画布组合与主题颜色绑定
```

按仓库文件结构准则，先让 `structure.rs` 保持清楚；只有实现增长到多个独立职责时才新增子目录和文件，不预建空模块。新 Rust 源文件首行用中文功能注释。Qt/C++ 的按键映射和绘制职责分开，不把键盘输入、指针处理和结构布局塞回单一大文件。

## 验收标准

- [ ] 段落、标题、块环境与列表项可按快捷键导航；界面仅显示通用结构类别，Rust 保留具体结构语义。
- [ ] `\section` 将当前段落转换为带独立标题的 Section；`\environment` 将当前段落包入 Custom 容器；两者都有焦点结构投影且可撤销/重做。
- [ ] Custom 保留可选实例显示名和主题模板引用；显示名须为非空、无控制字符且不超过 128 个 Unicode 字符，名称不需要注册表登记。
- [ ] 块环境可嵌套、选中并删除；显式提升操作保留子项；失败命令不产生部分文档修改。
- [ ] 删除普通标题只删除标题段落，不隐式删除由大纲层级派生的后续范围；逐级扩大选区可覆盖段落和标题。
- [ ] 标题、环境标题和列表项的插入/删除/级别变更后，受影响结构范围正确；增量结果与完整重建一致。
- [ ] `at(pos)` 返回稳定 ID 构成的外到内结构栈；行内格式和 `InlineMath` 不产生块级停靠点。
- [ ] 可导航结构在同一布局快照中有实际页内几何；跨页范围映射正确，结构范围变化不会伪装成内容绘制变化。
- [ ] 焦点框跟随当前结构，滚动和缩放不改文档；焦点颜色使用 QML Theme。
- [ ] 键盘路由不与命令输入、IME、选区和 UI 弹层冲突；撤销恢复文档与位置状态。
- [ ] `caret-structure` 依赖方向符合分层规范；无重复实现、孤儿文件或无用依赖。
- [ ] 结构索引不进入布局缓存键；仅影响结构/大纲语义的变更更新索引，纯字色、字体度量和主题来源变化不触发结构索引重建。
- [ ] 按测试规范验证；fmt、lint、相关行为测试及独立评审通过。未执行的人工验收明确记录。

## 风险与回退

焦点框若有独立坐标来源会与分页/缩放错位；必须消费布局快照的结构范围。若几何或性能不满足要求，可暂时关闭焦点框，但保留结构索引和命令行为。
