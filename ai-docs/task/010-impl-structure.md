# 010 — M2：结构导航

- 状态：planned
- 依赖：009
- 优先级：P2
- 创建 / 更新：2026-10-25 / 2026-10-25

## 目标与背景

用户用键盘在段落、标题和列表项之间移动，并看见当前结构。这是需求的 M2。公式和表格的结构节点在 011、012 接上，本任务先把索引和焦点框用于已经存在的块。

## 必读

- [结构导航](../architecture/editor/structure-navigation.md)、[快捷键](../architecture/interface/keyboard-shortcuts.md)
- [命令](../architecture/editor/commands.md)、[分层](../standards/layering.md)

## 范围与非目标

创建 `caret-structure`。实现 `struct.next`、`struct.prev`、`struct.exit`，以及快捷键文档里的上一块、下一块和跳出。焦点框用结构栈和布局范围来画。状态栏显示当前结构。这两处都加在 007 的窗口上，不新开页面。

索引不写入文档，也不进入布局缓存键。样式代际变化时整份重建；本任务若还没有样式编辑，要有测试覆盖这条规则。

不包含：公式内部移动、单元格移动、逐级扩大选区以外的新选区模型。扩大选区若快捷键文档已列出，本任务实现到段落和标题为止。

## 前置条件与待决策

009 已 done。标题和列表已经能从 `\` 产生，索引才有节点可测。

## 实施步骤

1. 为段落、标题和列表项建索引。按结构导航文档区分块内节点与跨块范围失效，复用未变块的节点，更新受影响的节和连续列表边界。
2. 接入快捷键。作用域按结构导航文档，从内到外。
3. 画布画焦点框。滚动和缩放不改文档。
4. 测试：跨标题移动、在列表内移动、Esc 跳出。
5. 独立评审后复验。

## 预计改动

新建 `crates/caret-structure/`。`caret-engine` 持有索引。画布增加焦点框。FFI 增加结构栈所需的范围，不增加逐帧指针。

## 验收标准

- [ ] 标题和列表之间可以用快捷键移动，状态栏显示当前结构。
- [ ] 焦点框跟着当前结构，不触发额外排版。
- [ ] 标题改成正文、级别变化、插入和删除后，前序及祖先节边界正确；列表合并、拆分后范围正确。增量索引与完整重建一致。
- [ ] `caret-structure` 只依赖 `caret-doc` 和允许的 `caret-foundation`，不依赖引擎。
- [ ] 测试、fmt、clippy 通过。评审发现已处理。
