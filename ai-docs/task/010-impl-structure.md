## 目标与背景

用户用键盘在段落、标题、嵌套环境和列表项之间移动，并看见当前结构。这是需求的 M2。公式和表格的结构节点在 011、012 接上，本任务先把索引和焦点框用于已经存在的块。

## 必读

- [结构导航](../architecture/editor/structure-navigation.md)、[快捷键](../architecture/interface/keyboard-shortcuts.md)
- [命令](../architecture/editor/commands.md)、[分层](../standards/layering.md)

## 范围与非目标

创建 `caret-structure`。实现 `struct.next`、`struct.prev`、`struct.exit`，以及快捷键文档里的上一块、下一块和跳出。通过命令创建/嵌套块级 EnvironmentNode，并对可导航环境实现结构选择与删除：默认删除子树；保留内容时必须调用独立的提升子项操作。普通标题范围不是删除容器。环境操作使用命令和结构快捷键，不增加 QML 工具栏按钮。焦点框用结构栈和布局范围来画；当前环境背景高亮由 031 负责。为让结构框和 031 的块环境高亮共用实际几何，本任务须使 `Section`、`Showcase` 的标题与子块进入页面布局快照；不能再因 `Block::Environment` 而拒绝整份布局。行内粗斜体环境只参与格式和位置映射，不作为块级导航停靠点。状态栏显示当前结构。

索引不写入文档，也不进入布局缓存键。只有影响标题/大纲语义的结构代际变化才重建相应索引；字色、字体度量和主题来源变化不重建结构索引。本任务若还没有样式编辑，要有测试覆盖大纲样式代际。

不包含：公式内部移动、单元格移动、逐级扩大选区以外的新选区模型。扩大选区若快捷键文档已列出，本任务实现到段落和标题为止。

## 前置条件与待决策

009 已 done。标题和列表已经能从 `\` 产生，索引才有节点可测。

## 实施步骤

1. 为段落、标题、可导航的块级 EnvironmentNode 和列表项建索引。按结构导航文档区分显式子树与派生标题范围，复用未变块的节点，更新受影响的环境和连续列表边界。
2. 在页面布局快照中排入 `Section`/`Showcase` 标题和有序子块，保留分页顺序，并从同一快照提供容器及子项的页内范围。
3. 接入快捷键。作用域按结构导航文档，从内到外。
4. 画布画焦点框。滚动和缩放不改文档。
5. 测试：跨标题移动、嵌套 EnvironmentNode 选择/删除与提升、在列表内移动、Esc 跳出，以及块环境分页和范围映射。
6. 独立评审后复验。

## 预计改动

新建 `crates/caret-structure/`。`caret-engine` 持有索引并提供结构范围；`caret-layout` 将块环境标题和子项编入页面几何。画布增加焦点框。FFI 增加结构栈所需的范围，不增加逐帧指针。

## 验收标准

- [ ] 标题、嵌套 EnvironmentNode 和列表之间可以用快捷键移动，状态栏显示当前结构。
- [ ] 删除 EnvironmentNode 只影响明确选择的子树；提升子项保留内容；普通标题删除不隐式删除标题范围。
- [ ] 嵌套环境结构栈正确识别光标所在最内层 EnvironmentNode；焦点高亮不写入文档格式。
- [ ] `Section`、`Showcase` 标题和子块进入同一页面布局结果；结构范围/焦点框可映射到实际页内几何，环境节点不会使整份文档布局失败。
- [ ] 焦点框跟着当前结构，不触发额外排版。
- [ ] 标题改成正文、级别变化、插入和删除后，前序及祖先节边界正确；列表合并、拆分后范围正确。增量索引与完整重建一致。
- [ ] `caret-structure` 只依赖 `caret-doc` 和允许的 `caret-foundation`，不依赖引擎。
- [ ] 测试、fmt、clippy 通过。评审发现已处理。
