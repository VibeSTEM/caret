# 046 — M3：表格布局与画布

- 状态：planned
- 依赖：027、045
- 优先级：P2

## 目标与背景

把 045 的表格模型与现有 Rust 布局、Qt 画布连接起来，使网格、单元格内容、点击命中和键盘焦点使用一致的单元格几何。表格单元格中的公式布局、绘制、命中和导航也由本任务验收，复用 044 提供的公式快照；表格模块本身不拥有数学排版策略。总体验收见 [012 M3 表格](012-impl-table.md)。

## 范围与非目标

实现表格行/列/单元格的尺寸计算、网格绘制快照、单元格内容布局、分页/裁剪、命中测试与焦点几何。单元格内容保持通用块序列；把 044 公式快照放入单元格内容区域，并将同一坐标变换和裁剪应用于公式绘制、命中与焦点几何。

不实现公式解析或数学字体/MathBox 布局，不接入 `latex-rust`；公式 glyph/rule 通过 044 的快照绘制路径呈现。不实现单元格合并，也不承诺表格级增量性能门槛。

## 前置条件与待决策

045 表格结构和 027 画布命中能力完成。采用的列宽/行高默认及页面溢出行为应符合现有段落排版契约，不在此任务新定义分页语义。

## 实施步骤

1. 计算单元格可用矩形、边框/网格和内容起点，使用统一整数度量。
2. 布局单元格中的多个段落和嵌套块；跨页片段保留单元格/块路径映射。
3. 将鼠标命中和焦点导航映射到同一单元格布局数据，确认滚动、缩放与分页后坐标一致。
4. 消费 044 的数学快照并应用单元格内容区域、裁剪和坐标变换，不把公式布局策略放入表格模块。
5. 补多列宽、多段、空单元格、跨页、命中和缓存行为测试；记录性能基线，不在没有数据时设时限门槛。
6. 更新 012、027 关联说明，独立架构与代码评审后复验。

## 预计改动

`crates/caret-layout` 表格布局；现有 Qt 画布/FFI 快照仅添加承载表格几何所需字段。具体文件边界按仓库拆分准则确定。

## 验收标准

- [ ] 网格和单元格内容跨页正确显示；单元格多段内容、长内容和空段布局可验证。
- [ ] 点击、拖选起点、键盘焦点与滚动/缩放后的命中共用同一几何结果。
- [ ] 单元格中的 InlineMath、Equation 和 Align 使用 044 公式快照正确布局、绘制、命中并导航；表格基础布局不依赖 `latex-rust`。
- [ ] 页面 generation 变化时旧的表格命中/绘制快照不会覆盖新结果。
- [ ] 行为测试、跨层构建/lint 与独立评审通过；性能报告记录实际输入与配置。

## 风险与回退

表格与段落基线/分页耦合较强。复用现有 PageFragment、段落布局和 hit-test 契约，避免在 Qt 重写坐标或在表格里复刻段落算法。若分页复杂度超出首版，保留完整文档模型并限缩布局行为，不序列化成图片。
