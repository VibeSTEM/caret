# 061 — 字色、高亮与字符底纹

- 依赖：022、024、027

## 目标与背景

实现字符范围绘制类格式，并维持字色、文本高亮、字符底纹三种含义。它们改变绘制但不改变 Parley 行框、分页或文本位置；Rust 保存并解析格式，Qt 只消费绘制投影。

- [格式语义](../architecture/editor/text-formatting.md)、[文档模型](../architecture/editor/document-model.md)、[画布高亮架构](../architecture/interface/canvas-highlighting.md)
- [分层](../standards/layering.md)、[QML 规范](../standards/qml.md)、[测试](../standards/testing.md)

## 范围与非目标

- 为选区、插入点和 pending typing 提供字色、文本高亮、字符底纹命令及清除/继承语义。
- 分别表示自动字色、主题色引用、显式颜色、语义高亮及任意 RGB 底纹；页面色、工作区色、当前环境高亮不混入字符格式。
- 定义文本高亮与字符底纹并存时的绘制层级；颜色解析和选区状态由 Rust 提供。
- 复用现有 QSG 绘制路径，不让绘制格式触发行框重算或由 QML 持有文档格式。
- 不实现字号、段落格式、文档主题编辑 UI 或打印色彩管理。

## 前置条件与待决策

- 实施前确定颜色值类型、主题 token 引用稳定性、透明度支持和未知值策略，并更新格式语义文档。
- 高亮与底纹使用不同命令和可观察状态；颜色选择复用通用交互组件，不复制权威状态。
- 明确跨字素、软换行、RTL、多行和分页时的矩形绘制规则。

## 实施步骤

1. 核查 Run 模型、装饰几何和 QSG 图层，定义唯一格式到绘制数据流。
2. 定义持久化值、能力标记、命令状态和优先级。
3. 实现 Rust 事务/查询与绘制投影，Qt 仅依投影绘制。
4. 增加可观察行为和画布像素验证，证明绘制变化不重塑字形或改变段落几何。
5. 测量长选区格式变化耗时/分配，补齐翻译并完成独立评审。

## 风险与回退

合并不同绘制语义会丢失主题、打印或编辑含义；让 QML 解析持久化格式会引入第二套规则。保留 Rust 解析结果和独立 QSG 绘制职责，更新数据先在副本中验证。
