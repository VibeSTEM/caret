# 063 — 文档排版主题与命名样式

- 状态：ready
- 依赖：020、021
- 优先级：P2
- 创建 / 更新：2026-10-30 / 2026-10-30

## 目标与背景

完善 `.cdoc` 文档排版主题、命名 Run/Paragraph 样式、全局覆盖与显式更新生命周期。该能力决定格式回退来源及缓存代际，与具体格式命令分开；不涉及应用 QML Theme。

## 必读

- [格式语义](../architecture/editor/text-formatting.md)、[文档模型](../architecture/editor/document-model.md)
- [文档树与存储](021-document-tree-and-storage.md)、[分层](../standards/layering.md)、[测试](../standards/testing.md)

## 范围与非目标

- 定义命名 Run/Paragraph 样式稳定 ID、属性白名单、文档默认样式引用和 `globalSettings` 覆盖语义。
- 完成主题快照载入、校验、显式更新、引用检查、原子替换及 `.cdoc` 保存/重开行为。
- 按样式变化的实际影响推进 generation 和缓存失效；无效主题不得破坏旧快照。
- 保持优先级：Run/Paragraph 直接属性 → EnvironmentNode 有效设置 → 文档全局覆盖 → 主题命名样式 → 应用默认值。
- 不实现 Office/DOCX 兼容、056 字体设置 UI、应用 GUI Theme 或外部主题路径依赖。

## 前置条件与待决策

- 实施前核对现有 `ThemeSnapshot`、环境模板、自定义定义与 `requiredFeatures`，避免重复创建主题系统。
- 明确当前主题文件唯一版本结构、命名样式 schema 和未知字段策略；未知可选字段保留，未知必需能力拒绝写入。
- 被删除或变更的样式/环境引用须按明确规则拒绝或迁移，不能静默重解释文档。

## 实施步骤

1. 审核快照与格式解析，形成字段、能力标记、优先级和 generation 权威表。
2. 先补文档模型/格式语义缺口，再实现校验和迁移。
3. 接入主题快照载入、显式更新和保存重开，不让 QML 解析样式。
4. 验证优先级、未知字段、引用丢失、更新失败原子性、异步 generation 与缓存失效。
5. 更新文档和性能证据，完成独立评审及复验。

## 预计改动

`caret-doc` 快照/schema、`caret-engine` 样式解析和 generation、`caret-app` 主题文件服务/显式更新 API、必要的 FFI 投影及架构文档。只有稳定独立复用和依赖边界成立时才考虑抽 crate。

## 验收标准

- [ ] 样式 ID 与属性白名单稳定；直接值、环境、全局覆盖、命名样式、默认值优先级由行为验证固定。
- [ ] `.cdoc` 内嵌当前快照，不依赖外部路径；未知可选字段保留，未知必需能力拒绝写入。
- [ ] 显式更新先在副本验证；失败时保留原快照、文档 revision、撤销历史和引用。
- [ ] 样式变化按影响类别推进 generation；过期布局/绘制结果不能覆盖新状态。
- [ ] 保存重开、旧已知版本迁移、更新失败和引用变化有行为验证；长文档失效范围有性能数据。
- [ ] 文档规范、任务索引及独立 final review 同步完成。

## 风险与回退

样式解析位于排版关键路径；重复解析、无稳定引用或部分替换会造成全篇外观漂移。校验、迁移和替换需事务化，并保留旧快照直到新快照验证成功。
