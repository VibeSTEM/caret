# 022 — 文本编辑、选择与 IME

## 目标与背景

实现基础输入、删除、光标和选区命令，统一 UTF-8 存储位置、Unicode 字素移动和 IME composition。字素到 glyph cluster 的视觉映射由 024/027 接通。

## 必读

- [文档模型](../architecture/editor/document-model.md)、[命令](../architecture/editor/commands.md)、[文字塑形](../architecture/editor/text-shaping.md)
- [分层](../standards/layering.md)、[FFI](../standards/ffi.md)、[测试](../standards/testing.md)

## 范围与非目标

实现 Rust 编辑核心中的 `text.insert`、`text.delete`、`caret.move`、选区、段落拆分/合并、软换行和 IME 提交/取消。按 020 的标题规则，在块环境标题内 Enter 时将后半段转为正文首段。修改走 `Session::run`，位置规则遵循 020。Qt/C++ 输入 DTO 和真实 IME 信号接线留在 008 的 FFI/ViewModel 集成中；022 提供 Qt UTF-16/ Rust UTF-8 转换和稳定命令语义。

不包含格式 UI、反斜线命令、协作编辑或正式 Undo/Redo；历史由 018 跟进。

## 前置条件与待决策

021 文档模型和 .cdoc 可用。022 不维护第二份正文或另定义位置单位。

## 实施步骤

1. 明确 UTF-8 offset、用户可见字素边界与 IME preedit 的桥接契约；以 Rust `Command` 和 UTF-16/UTF-8 转换函数固定语义。
2. 实现命令和事务失败语义。
3. 验证命令事务、IME 提交/取消和重复通知；Qt DTO/真实输入法接线由 008 验收，视觉位置映射由 027 验收。
4. 独立评审并复验。

## 预计改动

`caret-engine` 编辑命令、Unicode/IME 位置转换和命令行为测试。

## 验收标准

- [x] 同一 Unicode 版本的扩展字素簇规则作用于 Paragraph 逻辑文本，跨 Run 和 Bold/Italic/Font 节点分段；格式边界不能制造额外光标停靠点。测试覆盖组合重音、跨 Run/环境拆开的 emoji ZWJ/肤色序列、中文、Indic 组合和阿拉伯组合标记，不依赖 shaping 的 glyph cluster 输出。
- [x] 选区端点验证完整字素边界，外部非法 Pos 明确拒绝，不静默拆开字素；格式选区吸附留给格式命令任务。
- [x] 输入与编辑不隐式规范化 Unicode 码点序列；测试保留 NFD 码点。
- [x] 编辑位置保留 affinity，范围操作使用事务位置映射；测试覆盖边界转移和组合位置映射。格式继承状态随格式命令任务实现。
- [x] IME 更新不写入文档；提交仅插入一次，取消无副作用；composition 期间拒绝改动文档选区或执行段落命令。
- [x] composition 映射到文档时保留原始码点序列；Enter/编辑由输入法待提交期间优先消费留给 008 的 Qt 接线验收。
- [x] Qt UTF-16 与 Rust UTF-8 映射拒绝代理对中间位置，且不改变逻辑位置。
- [x] 正文 Paragraph 中 Enter 创建段落，软换行保留当前环境作用域；环境标题按 020 的独立标题规则处理。
- [x] 段落合并校验语言、段落属性和 markStyle；不兼容时拒绝。未知字段归属无法安全判断时拒绝且不改文档。
- [x] 块环境标题 Enter 保留前缀，新建正文首段放入后缀并插到现有子项前；测试覆盖现有段落/嵌套环境顺序和空后缀。
- [x] 跨标题/正文选区与未提交 IME composition 有明确拒绝结果，失败不丢失标题/正文内容。
- [x] 失败命令保持文档、选区和待输入状态不变。
- [x] 已知节点未知可选字段在局部插入后保留；未知字段归属无法安全分配的结构拆分原子拒绝。
- [x] 独立评审问题已修复并复验。

## 风险与回退

字节偏移不能直接当作字符移动步长。所有移动、删除和命中走统一映射；映射不可用时拒绝猜测。当前首版逻辑文本映射按需构建并在光标导航期间缓存，文档修改后失效；单段极长文本的延迟与内存需由 013 基准测量后再决定增量索引。普通单点插入/删除在已解析目标段落上原位更新，避免额外复制整段。
