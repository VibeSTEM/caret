## 目标与背景

实现 `.tex` 所有 Caret 内容的导入导出。必须等待 047 所依赖的全部文档模型、媒体、排版和画布能力完成；不先做文本或公式子集。数学表达式 parser/layout 不等于完整 TeX 文档 parser；格式边界见[文档格式导入与导出](../architecture/editor/document-interchange.md)。

## 范围与非目标

- Caret 文档模型中的所有节点、媒体、表格与公式均能输出到原生 LaTeX 结构或版本化 Caret 扩展，Caret 自己可完整往返重开。
- 定义可安全导入的标准 TeX 子集；其他 TeX 功能要能定位并报告。
- 仅解析静态源；不执行任意宏、shell escape、外部程序、用户包或 TeX 代码。
- 显式报告用户宏、包命令、复杂环境及目标模型不能表达的特性；需要时拒绝转换。
- `latex-rust` 仅用于其已验证的数学解析/布局能力，不视为整份 TeX 文档解析器。
- 不承诺 LaTeX 排版结果逐页或逐像素复刻，不保存第三方 AST 为 `.cdoc`。

## 前置条件与待决策

- 010、011、012、021 已完成，目标语义可表达结构、公式与表格。
- 实施前评估 Rust TeX 文档解析库的覆盖、许可证、安全性和维护情况；逐项记录复用或自研原因。
- 选定并文档化安全输入子集、Caret 扩展语法及源位置诊断方式。

## 实施步骤

1. 以有代表性的 TeX 源样例验证 parser 能力，不调用 TeX 引擎执行源文件。
2. 构建 TeX 专属语法表示（仅在适配器边界需要时）并映射到 Caret 树。
3. 从 Caret 树生成受支持的 TeX 子集，输出不支持语义报告并采用原子写入。
4. 测试结构映射、拒绝/降级、恶意命令与失败副作用；独立评审并更新任务记录。

## 预计改动

新增 TeX 格式适配器与测试；不把 `latex-rust` parser AST 扩散到 `caret-doc` 公共持久化类型。

## 验收标准

- [ ] 所有 Caret 文档节点和媒体资源都能输出到原生 TeX 或 Caret 扩展，并从自身扩展完整重开。
- [ ] Caret 扩展和可读 TeX 回退内容的一致性可校验；回退被修改时报告冲突，不静默恢复旧扩展内容。
- [ ] 安全支持的外部 TeX 输入可映射到 Caret；其他结构有可定位报告，不执行用户宏或 TeX 程序。
- [ ] 任意宏或活动命令不执行；未支持构造有明确诊断，必要时拒绝。
- [ ] 导入失败不替换会话，导出失败不留下半成品目标文件。
- [ ] 数学公式走 011 定义的公式模型；表格走 012 定义的模型。
- [ ] 测试覆盖结构结果、转换报告和安全失败副作用，不依赖私有实现断言。
- [ ] 依赖审计、独立评审和验证结果均已记录。

## 风险与回退
