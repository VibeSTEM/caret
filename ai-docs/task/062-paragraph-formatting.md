# 062 — 段落格式命令

- 状态：ready
- 依赖：022、026、027
- 优先级：P2
- 创建 / 更新：2026-10-30 / 2026-10-30

## 目标与背景

为段落级直接属性提供一致命令与编辑行为。`ParagraphLayoutOverrides` 和排版算法由文档模型及 026 定义；本任务接通用户操作，不在命令层重复实现排版公式。

## 必读

- [格式语义](../architecture/editor/text-formatting.md)、[文档模型](../architecture/editor/document-model.md)、[段落排版](026-paragraph-layout.md)
- [命令](../architecture/editor/commands.md)、[数值与单位](../standards/numeric-values.md)、[测试](../standards/testing.md)

## 范围与非目标

- 评估并实现模型已支持的对齐、段前/段后距离、行距、分页控制等段落属性命令；只纳入行为定义清楚的属性。
- 支持单段、多段选区、mixed 状态、局部清除并回退文档默认样式；每个用户动作是一次事务与一个撤销单元。
- 复用 026 的布局解析和失效机制；页面尺寸/边距继续由 PageSection 管理。
- 不改变分页算法，不新增单位，不实现字符格式或命名样式编辑器。

## 前置条件与待决策

- 开工时核实字段在模型与 026 中的语义；缺规则则先补权威文档，不能在命令中自行推断。
- 先定义命令候选、参数输入、mixed 选择、错误反馈和取消行为；状态仍由 Rust Session 持有。
- 明确跨 Section/表格单元格的选择和事务范围、位置映射。

## 实施步骤

1. 建立模型字段—命令—布局效果—失效范围映射表。
2. 实现 Rust Session 命令、查询投影和事务，并复用现有段落样式/分页路径。
3. 接入 QML 参数和状态呈现，覆盖 locale、焦点、IME 和取消。
4. 增加选区、持久化、分页、撤销行为验证，测量局部和全选修改代价。
5. 同步文档/翻译，完成独立评审和复验。

`caret-engine` 段落格式命令/Session、命令注册表、必要 FFI/Qt/QML、`caret-doc` 缺失的字段校验和行为测试。不新建与 026 重复的布局模块。
